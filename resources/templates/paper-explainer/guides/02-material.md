# 论文讲解：收集与处理材料

这一阶段不能省略：页面上的每个数字、每条论断都要能在材料底稿里找到来源与条件。先取得全文（优先用户提供的 PDF 或全文；只有编号或链接时，在宿主能抓取或读文件的前提下从公开入口取得并记录版本与日期，否则请用户提供），再逐节取材，不依赖摘要或他人综述。

## 论文各部分提供什么

| 论文部分         | 取什么                                                   | 常见陷阱                                                         |
| ---------------- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 摘要、引言、结论 | 主张的原话；作者自己给的贡献列表                         | 摘要里的数字常省略条件，必须回到表格核对                         |
| 相关工作         | 论文默认读者已会的概念；与前作的差异点                   | 差异点常是机制讲解的起点                                         |
| 方法节           | 参与的对象、记号、每一步对对象做了什么、关键参数与默认值 | 框图省略了状态变化，要从文字和公式里读出"改变了什么、保留了什么" |
| 实验设置         | 数据集、基准、对照对象、推理或评测模式、评测次数、算力   | 设置节与表注分别给条件，二者都要看                               |
| 主结果表         | 原值、每列最优、本文相对对照的差值与倍数                 | 不同表的口径可能不同，不能跨表比较                               |
| 消融             | 基线与改动的原值；每组消融在回答什么问题                 | 消融基线可能与主结果基线不同                                     |
| 案例、附录       | 成功与失败形态、作者自列的限制、未公开的数据             | 最重要的限制常在附录或脚注                                       |

## 数字怎样记才能用

每个将出现在页面上的数字记四项：数值；位置（段落、表号、图号，标注值还是正文值）；条件（数据集或基准、对照对象、推理或评测模式、评测次数与均值口径、是否重新评测、算力是否对齐）；本次用途。条件通常分散在设置节、表注和附录，要合在一起记。相对值（差值、倍数、名次）只记原值，由组件计算或在正文注明算法；论文图中标明为示意的数值记为"示意值"。没有条件的数字不进入页面。

## 论断怎样按证据强度分类

读者引用论文前需要知道一条论断靠什么支撑。按论文的措辞与实验设置判断类型，常用类型如下：

| 类型             | 判断依据                                   | 记录要点                               |
| ---------------- | ------------------------------------------ | -------------------------------------- |
| 实测             | 训练或评测得到的结果，有表或图             | 重复次数；算力、数据是否对齐           |
| 离线重算         | 对同一批数据改算（换奖励公式、换分配规则） | 只说明分配或口径变化，不等于训练效果   |
| 推导             | 公式或性质层面成立                         | 依赖的假设；实际实验是否启用           |
| 作者承认尚未验证 | 局限、附录、脚注里作者自己列出的缺项       | 缺少的消融、检查点选择方式、口径未核对 |
| 讲解者补充       | 讲解者的推断或外部信息                     | 单独标注，不混入论文论断               |

类型按论文增减：理论论文可能主要是推导与数值验证，评测论文可能有"人评实测"与"估算"。分类的目的是让读者知道哪些可以直接引用、哪些要附条件、哪些还没有被证明。

## 贯穿例子、术语与图像

论文通常有自己的贯穿例子（一个任务、一段视频、一条轨迹）；找到它并记录出处，后面问题、机制与案例沿用同一例子，不另造。记录新引入的记号、缩写与公式变量：首次定义位置、一两句准确含义（是什么、形状或单位、在论文中的取值），以及一句直觉类比；它们会成为正文解释或悬停注释的内容。记录要用的原图（图号、版权状态），以及准备生成示意图时必须保持准确的对象、数量、箭头与标签。

## 缺口

缺少对照实验、算力未对齐、某分支没有完整曲线、训练数据未公开、外部成绩协议不一致，都作为限制写入底稿。不补造数据，不绘制没有完整数据的曲线；缺口会成为成品中明确可见的限制。
