# 论文讲解：呈现设计稿

环境默认 1440×900、可交互。为呈现逻辑的每个环节写一幕，字段按系统规则（form、composition、text、interaction、static、narrow、assets、check）。下面给出每幕在两篇实例中成立的画面、文字模式与组件选择；本篇按材料调整对象与数字。

## 整体布局

一条纵向阅读流，章节编号直述主题（“2. 机制：一个打分头同时做时间定位和选择题”）。每个组件前放一段导语（接下来看什么、用哪个例子、怎样操作，例如“先猜再拖动验证”），后面按需放“读图要点”（三条以内，看完应能回答什么）。机制小节首段以“结论：”开头。保留意见用固定短语成段：“没有被证明的部分：”“实验上的限制：”“讲解者补充：”，不混进叙述。

角色色在全页固定：为论文中的稳定对象（策略模型、价值模型、奖励、视频片段、问题、候选……）各分配一种颜色，所有图形、泳道、片段条沿用；主张、证据、注意三类要点用三种固定标记。局限、未验证与参考值的标记默认可见。

## 每幕的画面

| 幕 | 画面（composition 的起点） | 交互 | 组件 |
| --- | --- | --- | --- |
| 首屏 | 顶部出处行（编号、日期、页数、链接）与原题；中央一句话结论加粗；下方四格“问题 / 做法 / 结果 / 注意”或三档深度（1/5/20 分钟）的要点列表；底部三四个关键数，每个带“对照对象 · 口径”小字；右侧或底部按时间预算的阅读路径指向真实章节 | 切换深度；点击路径跳转 | 论文速览卡 `paper-glance` 或论文简报 `paper-brief`（二选一）；无库时用 metrics 加正文要点 |
| 术语 | 胶囊按“基础概念 / 本文方法 / 评测口径”三组排列；点击在下方展开定义、直觉类比与所在章节 | 点击展开；一键全部展开 | 术语速查 `term-strip`；无库时用 table |
| 问题 | 用贯穿例子的真实画面：左右并排现有做法与本文做法对同一输入的处理，差异处（逐 token 生成 vs 一次读出；重复计算 vs 共享前缀）用颜色与标签标出 | 点击片段看作用，其他片段降饱和 | 序列布局图 `sequence-layout`，或 mechanism-steps 的两帧对比 |
| 方法总览 | 横向阶段 × 纵向对象的泳道矩阵：每格写更新 / 冻结 / 继承 / 准备，继承用虚线穿过；底部一行逐阶段指标 | 点击阶段看这一步做了什么；点击泳道追踪同一对象 | 阶段泳道图 `stage-lanes`；无库时用 mechanism-steps 逐帧标出改变、承接、固定的对象 |
| 难题与对策 | 左列难题（症状与数字），右列对策（做法与作用位置），中间编号连线；展开显示“为什么这样能解决”、证据强度、下文位置 | 点击一对展开 | 难题→对策映射 `problem-fix-map`；无库时用 comparison-matrix 或双列 table |
| 机制细节 | 同一组对象的连续状态变化（编码 → 拼接 → 前向 → 打分 → 解码），每帧标出改变、承接与固定的对象；或一条交互链在不同规则下的权重热度行 | 上一步 / 下一步；切换规则；重置 | mechanism-steps；论文特有机制新建组件 |
| 可操作参数 | 时间轴上每个候选一根柱，阈值水平线可拖；或几条公式曲线共享横轴，参数滑块与游标显示同点取值 | 拖动阈值或滑块，读数与选中区间实时变化；重置回论文设定 | 公式曲线 `formula-curves`、playground；专题交互新建组件 |
| 主结果 | 行是模型或指标，列是基准或阶段；本文行高亮，其下显示相对骨干或前一列的差值与倍数；每列最优加粗；口径写在列说明与脚注 | 按组筛选；只看对照 | 基准对照表 `benchmark-compare`、指标矩阵 `metric-matrix`；无库时用 table 并在正文写差值 |
| 同行位置 | 条目按数值降序的横向条形，标出名次，本文条目高亮；多组数据用标签切换 | 切换基准 | 排序对照条形 `rank-bars`；无库时用 chart 条形图 |
| 消融 | 每张卡：问题 → 基线 vs 改动 → 各指标差值条（正右负左）→ 结论；可展开细节与表号 | 展开 | 消融发现卡 `ablation-findings`；无库时每个消融一段加 metrics |
| 案例 | 表格：基准 / 时长 / 任务 / 标注 / 各模型输出 / 结果形态；或点击阶段看一条轨迹每步发生了什么 | 点击阶段 | table；`stage-lanes` |
| 口径与局限 | 加粗小标签各带条目（延迟怎么算 / 输入怎么采样 / 基线怎么跑 / 什么没算）；适合 / 不适合两列表 | 无 | 正文与 table |
| 可信度 | 论断逐条列出，标注证据类型、证据摘要、原文位置与限制；按类型筛选 | 筛选 | 论断证据账本 `claim-ledger`；无库时按类型分节的 table |
| 自测 | 四到六题，选择后立即显示对错、解释与对应章节；只存阅读状态 | 作答、重做 | 理解自测 `self-check`；无库时题目加折叠答案 |
| 来源 | 一句固定说明（数字取自哪些表与图、示意值如何标注、读取日期与版本）；原文链接；延伸阅读 | 无 | bookmark、references |

带反引号的名字是论文讲解组件库中的局部名；模板附带组件库时 `template_context` 返回它们的精确引用，用其 guide 与 parameters 准备数据。没有组件库时用右列的内置替代，画面要求不变。论文特有机制（候选分数解码成区间、多轮交互中的信用衰减、两条通道的可访问性差距等）当读者需要改一个参数并看到结果变化而上述组件表达不了时，按 create-component 新建，对象与颜色沿用本页角色色。

## 每幕要求

- 首屏在 1440×900 不滚动可见一句话结论、关键数与口径；不重复 Page 标题。
- 机制幕保持同一组对象身份，颜色按角色固定，跨幕一致；默认状态即论文设定；交互只改变阅读焦点，写清恢复方式。
- 证据幕只在同一口径内比较；不同口径分表或分节，差异写在脚注或行说明；参考值标明来源。
- 示意数据在组件的说明字段标明，并在正文与来源节重申。
- 每幕写 static（静态导出显示哪一帧或哪个状态）与 narrow（窄于 640 px 时怎样换行或改为纵向）。
- 制作后为每幕记录真实 blockIds，评审按幕核对：数字与原值一致、派生值正确、交互可恢复、术语都有定义、来源可打开。
