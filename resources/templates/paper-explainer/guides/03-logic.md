# 论文讲解：呈现逻辑

## 第一级：主干

两篇已验证实例共同的主干如下。按本篇材料增删和改名，不照抄名称；每个环节写一句读者读完应知道什么。

| 环节 | 主题 | 读者读完知道 |
| --- | --- | --- |
| 首屏 | 一句话结论、论证骨架、关键数与阅读路径 | 这篇论文做了什么、最重要的数字及其对照对象、最重要的限制 |
| 问题 | 现有做法为什么不行，用论文自己的贯穿例子 | 成本或误差来自哪里 |
| 方法总览 | 每一步更新、冻结、继承了什么；或输入怎样排列 | 整体流程与稳定对象 |
| 难题与对策 | 方法的每个组件对应哪个难题 | 每个设计为什么存在 |
| 机制细节 | 一到三个核心机制，每个先给结论再给可操作画面 | 能预测改参数后的方向 |
| 证据 | 主结果、与前作或前沿的对照、消融、分层、案例 | 提升在哪里、有多大、口径是什么 |
| 口径与局限 | 读数字前必须知道的条件；什么时候不该用 | 不会误读倍数与差值 |
| 可信度 | 实测、离线重算、推导、作者承认未验证 | 哪些可以直接引用 |
| 自测 | 四到六题，覆盖主张、机制、条件、口径、证据强度 | 读懂了吗 |
| 来源 | 数字取自哪些表与图、示意值怎样标注、读取日期与版本 | 可以回查 |

可选环节：术语速查（正文反复出现的缩写超过六个）、训练配方、按难度分层、训练动态与被舍弃分支、置信度校准、适合与不适合判断表、延伸阅读。论文有对应材料且读者任务需要时加入，没有就合并进相邻环节或省略。

## 第二级：每个环节讲清什么

- 首屏：主张一句；三到四个已核实的数各带对照对象与口径；最重要的限制一句；按时间预算（1 分钟 / 5 分钟 / 20 分钟）指向真实章节的阅读路径。
- 问题：贯穿例子是什么；现有做法对这个例子怎样处理；成本或误差具体来自哪一步（给数字）。需要先补基础角色分工（例如 actor 与 critic 各做什么）时在这里补。
- 方法总览：参与的稳定对象；每个阶段或步骤对各对象做了什么（更新 / 冻结 / 继承 / 准备）；阶段之间传递了什么；每阶段的一个指标。
- 难题与对策：每对写症状与具体数字、做法与作用位置、为什么能解决、证据强度、下文位置。
- 机制细节：每个机制一节，先一句结论；直觉解释；可操作的参数与预测方向；公式及记号含义；实验实际启用的设置；该机制没有被证明的部分。
- 证据：每张表的口径先说；本文模型相对骨干或对照的差值与倍数；哪一步贡献最大；分层或案例揭示的失败形态；每张消融卡回答一个问题。
- 口径与局限：延迟或分数怎么算、输入怎么采样、基线怎么跑、什么没算；作者承认或可从实验看出的边界；适合与不适合。
- 可信度：每条主要论断归入一个证据类型，附证据摘要与位置。
- 自测：每题对应一个理解任务，解释指向章节。

## 继续细化

叶子写清定义、过程、例子或条件，并给可观察的 check（“给出阶段名，读者能说出该阶段各对象的状态”“拖大阈值，读者能预测区间变窄”）。先备关系用 needs 标出：机制依赖贯穿例子与基础角色；证据依赖口径；自测依赖前面全部主干。熟悉主题的读者可以从难题与对策或证据直接进入，首屏阅读路径写明。

## 组织原则

答案先行再分层；先问题后方案；机制用稳定对象的状态变化讲，不用抽象框图；关键算法让读者亲手操作；每个数字带条件；消融按问题组织；局限与未验证内容显式可见，不放进折叠。
