# 论文讲解：呈现逻辑

这一阶段为这篇论文推出它自己的讲解顺序。顺序不来自论文的章节，而来自三个来源：读者简报里的检验任务、论文的贡献结构、论文的类型。下面的方法对任何论文都适用；标为"示例"的主干只是某些论文按这个方法得到的结果。

规划分两级做。第一级只决定整篇论文怎么讲：分成哪几个环节、按什么顺序、每个环节依赖前面哪些环节。第二级再逐个环节决定怎样讲清楚：要解释哪些概念、用哪个例子、给哪些证据、说明哪些条件。

## 第一级：从背景开始，层层递进

读者没读过这篇论文，在不知道任务是什么、现有做法差在哪里、方法怎样工作、实验怎样测之前，看不懂论文的结论和数字。所以不论哪类论文，第一级都从任务背景与动机开始，顺着论文的逻辑链条往下推：

- 每个环节只使用前文已经讲过的概念、例子和数字；读到任何一处都不需要后文的知识。
- 不设首屏总结、开篇结论或关键数字卡，也不在开头列"本文贡献"或全文结构摘要；结论放在支撑它的方法与证据之后出现。
- 背景只讲后文需要的部分：这类任务在做什么、输入输出是什么、为什么重要、现有做法怎样处理、具体在哪一步不够。动机落到论文要回答的那个问题，只说问题与思路，不提前报结果。
- 环节之间的衔接要显式：上一段留下的问题，就是下一段要回答的问题。

排完顺序后逐个环节检查：读到这里，读者是否已经具备理解它的全部前提。有前提在后面，就调整顺序或把前提前移；有一段需要读者"先记住、后面再懂"，就是顺序错了。

## 从读者简报推主干

把读者简报里的每个检验任务写在左边，右边写"哪一段讲解让读者能完成它"。没有任务对应的段落可以删，有任务没有段落就要补。再把论文的每条贡献（引言的列表，或自己归纳）对应到段落：贡献是机制的进机制段；贡献是结果的进证据段；贡献是资源（数据集、基准、工具）的要有"它是什么、怎样建的、能用来做什么"。证据段按主张组织，不按论文表格的顺序。

## 按论文类型选整体逻辑

先判断论文属于哪一类或哪几类的混合，再选起点逻辑。各类都从背景与动机开始，差别在后面的推进方式：

| 论文类型         | 背景与动机要讲清                         | 常见主干形态                                                                       |
| ---------------- | ---------------------------------------- | ---------------------------------------------------------------------------------- |
| 方法论文         | 任务是什么、现有做法在哪一步不够         | 背景与动机 → 本文思路 → 方法总览 → 机制 → 实验口径 → 证据 → 条件与局限              |
| 评测或数据集论文 | 要衡量什么能力、现有评测为什么不够       | 背景与动机 → 要衡量的能力 → 构建方式与口径 → 评测结果与发现 → 局限                  |
| 实证分析论文     | 要回答什么问题、为什么现有认识不足       | 背景与动机 → 问题与假设 → 实验设计 → 逐条发现 → 边界与反例                          |
| 理论论文         | 要刻画什么现象、已有结果缺什么           | 背景与动机 → 设定与假设 → 主要结果及直觉 → 证明思路 → 与实验或已知结果的关系        |
| 系统论文         | 面对什么工程需求与约束、现有系统卡在哪里 | 背景与动机 → 需求与约束 → 架构与关键决策 → 性能与代价 → 适用场景                    |

混合类型按主贡献选起点，其他贡献作为分支。表中的形态是起点，不是终点；下面的原则会继续调整它。

## 组织原则及其理由

每条原则解决一种读者困难；某篇论文没有相应困难时，对应段落不设。

- 背景与动机在前：读者先知道任务在做什么、为什么难、现有做法在哪里不够，才能理解论文的每个设计和每个数字。
- 先问题后方案：先用论文自己的例子说明现有做法为什么不行，读者才知道每个设计为何存在。
- 机制用稳定对象的状态变化讲：框图里的抽象名词无法让读者预测结果；列出参与对象，按步骤说每个对象改变了什么、保留了什么。
- 关键算法让读者操作：能改一个参数看结果方向的机制，读者才算理解；只在论文给了明确规则时设计操作。
- 先讲怎么测，再给数字：没有对照对象与口径的数字会被误读；读者先知道数据、对照与指标，结果才出现，条件在数字旁边可见。
- 消融按问题组织：每组消融回答"不这样会怎样"，比表格更容易读。
- 局限显式可见：作者承认的未验证项与讲解者发现的缺口放在主线，不折叠。

## 可选环节的加入条件

| 环节                   | 加入条件                                                                         |
| ---------------------- | -------------------------------------------------------------------------------- |
| 术语速查               | 正文反复出现的缩写或记号超过五六个；放在背景之后、首次大量使用之前，作为回查工具 |
| 训练配方               | 读者要复现，且论文给了完整设置                                                   |
| 按难度或子集分层       | 论文按难度、长度或域分层报告，且分层改变结论                                     |
| 训练动态与被舍弃的分支 | 论文展示了非单调的训练曲线或被放弃的变体，影响对结果的信任                       |
| 校准或置信度           | 论文的输出带概率，且被当作可信号使用                                             |
| 适合与不适合判断表     | 读者要决定是否采用                                                               |
| 自测                   | 讲解较长或读者要转述；题目对应检验任务                                           |
| 延伸阅读               | 论文的差异点依赖前作                                                             |

术语与记号在首次出现处就地解释；速查只用于回查，不代替背景与正文中的解释。

## 第二级怎样展开

对每个环节问它该回答的问题，答案就是它要讲清的内容：

- 背景与动机段：这类任务在做什么，输入与输出各是什么；贯穿例子是什么；现有做法对它怎样处理；成本或误差具体来自哪一步，有数字时给出并说明怎么测；由此引出论文要回答的问题和它的基本思路。
- 总览段：参与的稳定对象有哪些；每个阶段或步骤对各对象做了什么；阶段之间传递了什么。
- 机制段（每个机制一节）：它要解决前文的哪个难题；直觉；可操作的参数与预测方向；公式及记号含义；实验实际启用的设置；没有被证明的部分；最后点明它带来的改变。
- 实验口径段：用什么数据或基准、和谁比、指标怎样算、评测几次；不同实验之间口径哪里不同。
- 证据段：每张表在回答什么问题；本文相对对照的差值与倍数；哪一步贡献最大；分层或案例揭示的失败形态；每组消融回答什么。
- 条件与局限段：读数字时必须记住的条件（怎样算、怎样采样、基线怎样跑、什么没算）；作者承认或可从实验看出的边界。
- 可信度段：每条主要论断属于哪种证据类型，证据摘要与位置。

叶子写具体的定义、过程、例子或条件，并给可观察的 check（"给出阶段名，读者能说出各对象的状态""拖大阈值，读者能预测区间变窄"）。先备关系用 needs 标出：机制依赖背景、贯穿例子与基础角色，证据依赖口径，自测依赖前面的主干；needs 只能指向排在前面的节点。读者能完成对应任务时停止展开，各分支深度可以不同。

## 示例：两篇方法论文得到的不同主干

一篇用候选打分替代自回归生成来做视频判断的论文：背景（视频时间定位与问答任务、贯穿例子）→ 动机（生成式判断为什么慢、慢在哪一步）→ 机制（打分头、从分数解码区间与选项、两种复用模式）→ 训练配方 → 实验口径 → 证据（定位、问答、消融、问题数扩展、校准）→ 案例 → 局限与适用判断 → 来源。校准与案例因为论文有相应材料且影响"能不能用"才加入；没有术语速查，因为新缩写不多。

一篇递归自改进终端 agent 训练的论文：背景（终端任务与 agent 训练的现状）→ 动机（三个阻碍继续自改进的难题）→ 术语速查（缩写密集）→ 五阶段总览（对象在阶段间的更新、冻结、继承）→ 机制细看（每个对策一节，含可操作图）→ 实验口径 → 结果（各阶段、同行位置、难度分层、训练动态、案例）→ 可信度 → 自测 → 来源。难题段因为方法由三个独立组件构成才出现；训练动态因为论文展示了被舍弃的分支才加入。

两篇都是方法论文，都从背景与动机开始，后面的主干仍不同；差异全部来自上面的判断，而不是来自模板。
