# 论文讲解

从两篇经过验证的讲解页（VideoJev：把视频理解变成一次打分；Terminal-RSI 论文讲解）提炼。两页共同的做法：首屏一句话结论加带口径的关键数；先用论文自己的贯穿例子讲问题，再用稳定对象的状态变化讲机制；关键算法让读者亲手拖参数或点阶段；每张结果表只在同一口径内比较；消融按“如果不这样会怎样”组织；论文自己承认的未验证之处默认可见；最后用自测把“读完了”变成“能判断”。

四个阶段的指南分别规定：intent 的默认读者与可检验目标；material 中逐表逐图核对数字与条件的方法；logic 中可增删的主干与可选节点；design 中每一幕的画面、交互、文字模式与可用组件。组件按读者任务选择：模板附带组件库时用 `template_context` 返回的固定引用；没有组件库时按设计指南中的内置替代实现，论文特有的机制按 create-component 新建。

没有材料的可选段落合并或省略，不为填满结构制造内容；所有数字来自本次论文并带对照条件。
