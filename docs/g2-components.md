# G2 data charts

**Language:** English | [简体中文](i18n/g2-components.zh-CN.md) · [Documentation](README.md)

The Data category contains **43 built-in G2 charts**. Insert them in any project and configure title, height, typography, line width, palette, legend, animation and interactions. Data and field mappings are saved in the Page; reader theme changes affect only the current view.

## Data and fields

`datasets` holds one or more data sources. Most charts use `main`, layered charts use `layer-0`/`layer-1`, and maps use their example's named datasets. Read the selected component's schema, parameter reference and examples.

`fields` maps example field names to your data without changing the stored records:

```json
{
  "title": "Count comparison",
  "datasets": {
    "main": [
      { "label": "A", "amount": 4 },
      { "label": "B", "amount": 9 }
    ]
  },
  "fields": { "genre": "label", "sold": "amount" },
  "theme": "indigo",
  "height": 320,
  "appearance": { "palette": ["#120A8F", "#EA8A3B"], "fontSize": 14 },
  "interaction": { "tooltip": true, "elementSelect": true }
}
```

Kinds include `g2-bar`, `g2-line` and `g2-violin`. Agents use the same catalog, insertion and save operations as other components. A custom parent can import `G2Bar` and `G2Line` from `showai:components`. The compiler exposes approved SDK dependencies; arbitrary npm imports are unsupported.

## Rendering and delivery

G2 5.4.8 uses a local SVG renderer. Sunburst uses the official plot extension; Kagi combines basic shapes. Example datasets are upstream excerpts, map boundaries are simplified, and the example choropleth uses unweighted averages of county unemployment rates within states. Replace examples with actual data and state metric definitions.

Built-ins, derived components and offline HTML use the same drawing implementation and retain third-party notices. Invalid JSON, missing fields and rendering errors are reported.

Charts show a reading lock only for interactions that capture navigation, such as brushing, sliders, scrollbars or fisheye. Tooltips, hover and legend clicks alone need no lock. See [Page and Board](page-surface.md).

Defaults and metadata are generated by `scripts/generate-g2-components.mjs`; drawing code is in `src/components/blocks/g2/`, and editing is in `G2Chart.tsx`.
