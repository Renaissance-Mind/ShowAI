# ShowAI Cloud

**语言：** [English](../cloud.md) | 简体中文 · [文档目录](index.zh-CN.md)

官方账号/同步基址是 **https://showai.renaissancemind.ai/cloud**。在「设置 → 账号与同步 → 服务器账号 → 添加服务器账号」填写，不包含 /api。无注册密钥时可索取项目邀请，在「项目同步 → 加入共享项目」粘贴，通过邀请注册无需密钥。ChatGPT 使用独立的 [MCP 地址](chatgpt.zh-CN.md)。

## 账号、登录与服务绑定

支持已有 Token、账号密码，以及服务器已配置的 GitHub、Google、邮箱验证码。注册受密钥或项目邀请控制。第三方登录完成后显示一次性完成码与「在 ShowAI 中完成登录」链接，只有发起登录的窗口提交完成码后才确定账号。

在服务器卡片「账号与设备」添加/移除登录方式、生成个人 Token 前，需要最近 15 分钟直接登录该服务器；绑定服务恢复的会话不能授权这些操作。GitHub/Google 绑定需浏览器确认并填写完成码，后续仍登录同一账号；第三方创建账号至少保留一种登录方式。

分别登录服务后，可在「账号绑定」连接可信账号。新设备登录其中一个服务，凭短期签名授权恢复其他服务的独立设备会话；原 Token 不在服务器间分发。设备会话 30 天、个人 Token 一年，可在账号与设备撤销。退出所有设备同时退出本设备连接的绑定服务，无法连接的服务单独报告。移除连接注销该会话；已退出/撤销的账号需重新登录，只有自然到期会话可自动恢复。

绑定允许访问对应账号的项目与模型资源。解除绑定会撤销通过该来源签发的会话；离线目标保留待撤销，全部确认后才完成。

## 项目与模型资源

服务器账号卡片的「服务器上的项目」可下载远程项目；本地项目展开后用「上传到服务器」。管理员在「成员与邀请」管理编辑者/查看者与邀请。断网时本地继续编辑，认证和网络恢复后同步。

「在本设备显示」独立控制本机导航和最近页面，隐藏不删除内容或成员权限。

Agent 设置列出来源服务器与账号。可以使用服务器 API Key/ChatGPT 来源，或将本机来源保存到选定服务器。来源服务加密保存凭据并按认证设备需要提供，ChatGPT 刷新由来源服务负责；不可用时明确报错，不在整个绑定组复制凭据。Cloud 或配对 Mac 的执行设置见 [内置 Agent](agent-host.zh-CN.md)。

## 存储、配额与同步

客户端使用 SQLite 当前内容、稳定节点、并发 token 和恢复日志，本地保存与网络发布分别完成。WebSocket 推送变化，大更新通过 HTTP；事件不可用时调度器补偿，文件变化、前台活动和网络恢复唤醒同步。重试有界退避。

发布可以只携带自当前 head 改变的路径，服务器重建并校验完整清单；缺少基线时退回完整快照。Linux 使用 Node.js 24/SQLite/磁盘对象；Cloudflare 使用 SQLite Durable Object/私有 R2。超过 256 KiB 的对象在 Worker 与 R2 间流式传输，Durable Object 负责授权、计费和提交。D1 用于旧部署迁移。生产与 staging 的身份、数据、桶、密钥和基础设施凭据独立。

默认容量为每项目 1 GiB、每账号归属上传 2 GiB、每服务 64 GiB。对象上限 64 MiB、清单 16 MiB。上传先预留容量；未完成任务保留 24 小时，无任务的崩溃预留 15 分钟后释放。全站总量按分钟采样，可能短暂超出一分钟上传量；项目/账号计量精确。超配额或预算错误保留本地编辑。

## 运维与访问

内容服务配置为 deployments/cloudflare/wrangler.jsonc。[服务器运维](server-operations.zh-CN.md) 包含迁移、一致备份、保险库密钥、Linux 恢复、Durable Object 导入与回滚；恢复核验后只开放一份可写副本。

HTTPS 与项目成员认证保护访问。基础设施运营者可访问存储内容和保险库密钥，服务不提供端到端加密。账号 Token 与运维凭据用途独立，部署密钥应保存在仓库之外。
