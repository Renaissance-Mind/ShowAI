# 从 ChatGPT 连接本机 ShowAI

**语言：** [English](../chatgpt.md) | 简体中文 · [文档目录](index.zh-CN.md)

在桌面 App 打开「设置 → 远程连接」，按“选择方式 → 建立连接 → 连接客户端”完成配置。电脑需要保持联网、唤醒且 ShowAI 正在运行。

## 选择连接方式

Cloudflare 支持无需账号的临时连接，以及使用自己隧道的固定域名。Tailscale 使用已登录的账号和设备的 ts.net 地址。

新连接默认允许访问当前及以后新增的全部项目，并允许读取、编辑和远程新建项目。需要限制时，打开「访问规则」，选择指定项目并设置只读或完全权限。显式设置的访问规则会保留；旧版没有访问模式字段的配置采用新的全部项目默认值，旧受限客户端需要重新配对，确认新的授权范围。将仅授权指定项目的客户端改为全部内容库授权时，也需要重新配对。

## 建立连接

Cloudflare 临时方式依次点击「创建临时连接」及「下载工具并连接」或「建立连接」。ShowAI 会按需下载并校验官方连接工具，绑定可用端口并创建隧道。临时地址重新连接后变化，没有可用性保证；MCP 使用 JSON 响应，不依赖 SSE。

使用自己的 Cloudflare 域名时，选择「连接自己的域名」：

1. 点击「复制本机地址」，取得已经启动并保留的本机监听地址。
2. 点击「打开 Cloudflare 控制台」，创建 Cloudflared Tunnel 和发布应用路由，把 HTTP 服务指向上述地址。回到 ShowAI，点击「路由已配置，继续」。
3. 填入 HTTPS 域名和该隧道的令牌，建立连接。令牌由操作系统凭据存储加密保存，不需要账号 API Key。

固定域名优先复用上次保存的端口；端口被占用时，ShowAI 会保留另一个可用端口，并引导更新 Cloudflare 路由，不会结束占用端口的程序。临时 Cloudflare 和 Tailscale 始终转发程序自动分配的实际端口。配置公网地址期间，本机监听保持绑定。

使用 Tailscale 时，按当前步骤依次「安装并登录 Tailscale」「打开网络设置」，启用 MagicDNS、HTTPS 和 Funnel 权限，然后「已登录，检查并连接」。如果公网 443 已用于其他 Funnel，程序保留原配置并报告冲突，由用户在自己的账号中处理或使用专用设备。

失败时，当前步骤提供重试或返回配置的操作；「查看诊断」显示提供方的实际错误。公网检查通过后才进入客户端配对。

## 连接 ChatGPT

保持 ShowAI 运行，点击「复制 MCP 地址」，打开 ChatGPT 的「插件 → 添加 → 添加自定义 MCP 服务器」。入口是否可用取决于账号和工作区策略。按表填写：

| 字段 | 填写内容 |
| --- | --- |
| 名称 | **ShowAI 本机**，也可加上设备名，避免重名 |
| 连接 | **服务器 URL**，粘贴 ShowAI 中复制的 MCP 地址 |
| 身份验证 | **OAuth** |
| 高级 OAuth 设置中的「注册方法」 | **动态客户端注册（DCR）** |
| 客户端 ID / 客户端密钥 | 自动注册，无需手动填写 |
| 默认请求的权限范围 | 保留自动发现并勾选的权限；完全权限包含 `projects.read`、`projects.write`、`projects.create` |
| 基础授权范围 | 留空 |

Cloudflare 和 Tailscale Funnel 都选择「服务器 URL」。提示无法自动获取 OAuth 设置时，先在高级设置中点击「重试元数据发现」。成功后 DCR 可选，下面的地址会自动填入。ShowAI 的「处理自动发现失败」会显示当前连接各字段的准确值，并提供复制按钮。例如 MCP 地址为 `https://your-host/mcp` 时，授权网址、Token URL 和注册地址分别以 `/oauth/authorize`、`/oauth/token`、`/oauth/register` 结尾；授权服务器基础地址是 `https://your-host`，资源是完整 MCP 地址。PKCE 支持 S256，CIMD 和 OIDC 不可用属于正常情况。

仍发现失败时，检查 App 是否正在运行、隧道是否已开放公网。本机检查通过不等于 ChatGPT 已能连接；手动填写端点也不能修复网络问题。

核对权限与风险提示，勾选「我已了解，并希望继续」，点击「创建为插件」。提示同名时加上设备名。打开新插件，点击「连接」或「继续连接应用」。误关弹窗后，从「个人」或「已安装」列表重新打开该插件，继续连接即可。

ChatGPT 打开「连接本机 ShowAI」授权页后，回到 ShowAI，点击「已打开 ShowAI 授权页，继续」，再「生成配对码」。把码复制到授权页的「配对码」字段，点击「确认授权」。配对码十分钟内有效，只能使用一次；设置页显示剩余时间，并停止展示和复制已经过期、使用或被其他窗口替换的码。需要时点击「重新生成配对码」。

授权窗口也有独立的有效期。提示窗口失效时，回到客户端重新点击连接，再填写有效配对码。重新生成配对码不会恢复旧授权窗口。配对码只填在 ShowAI 授权页，不填到 OAuth 客户端密钥或聊天输入框。

连接后，在该插件点击「在聊天中试用」，或在新对话输入 `@` 选择它的准确名称，再发送从 ShowAI 复制的验证指令。真实的已授权工具调用成功后，设置页显示接入完成；仅创建插件还不代表已验证访问。

其他电脑上的 HTTP/OAuth MCP 客户端使用「其他 MCP 客户端」分支，无需在那台电脑安装隧道软件。接入后可以复制地址、连接另一个客户端、撤销客户端授权或断开连接。

页面直接保存到本机内容库，沿用版本和冲突检查。全部内容库授权自动发现后续项目；`project_create` 可以新建本机项目。创建响应不确定时，只为重试同一次创建沿用相同 operationId 与名称。另行配置的云同步需要分别核对状态。

退出 App 会关闭监听和连接器。固定域名的完整内容库授权在正常重启后保留；临时地址变化后需要更新客户端地址并重新配对。App 更新改变工具能力后，刷新客户端的 MCP 工具。保存中断时，重连后先读取 Page 再决定是否重试。预览链接一小时后过期，正式 Page 持续保存。

提供方参考：[Cloudflare 配置](https://developers.cloudflare.com/tunnel/get-started/)、[Tailscale Funnel](https://tailscale.com/docs/features/tailscale-funnel)。独立管理的云网关见 [MCP 部署](cloud-mcp-deployment.zh-CN.md)。
