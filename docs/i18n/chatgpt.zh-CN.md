# 在网页版 ChatGPT 中使用 ShowAI

**语言：** [English](../chatgpt.md) | 简体中文 · [文档目录](index.zh-CN.md)

通过托管 MCP 服务，可以在 [chatgpt.com](https://chatgpt.com) 的对话中创建、保存、续改和展示交互页面。完成账号设置后，日常网页使用无需运行本机 ShowAI，也无需单独安装 Skill。ChatGPT 账号和工作区需要允许自定义 MCP 服务。

## 1. 准备 ShowAI 账号

账号与同步基址是 `https://showai.renaissancemind.ai/cloud`。

注册目前受控。可以向运营者索取注册密钥，或向项目管理员索取邀请。在桌面或本地浏览器工作台打开「设置 → 服务器与同步 → 服务器账号 → 添加服务器账号」，填写该地址、账号名、至少 12 位密码和注册密钥。

通过邀请加入时，在「项目同步 → 加入共享项目」粘贴邀请链接，再通过邀请卡片注册；此方式无需注册密钥。已有账号可直接登录。仅保存在电脑上的项目需要先同步到此账号，远程 MCP 才能读取。

## 2. 添加 MCP 连接

打开 [ChatGPT Plugins](https://chatgpt.com/plugins)，选择「+ → Add custom MCP server」，创建为插件并安装。界面名称与可用性可能随账号或工作区变化，参见 [OpenAI 自定义 MCP 说明](https://developers.openai.com/api/docs/guides/custom-mcp-server#how-to-use)。

| 设置                      | 值                                            |
| ------------------------- | --------------------------------------------- |
| 名称                      | `ShowAI`                                      |
| 服务地址                  | `https://agent.showai.renaissancemind.ai/mcp` |
| 认证                      | **OAuth or no authentication**                |
| 提示 OAuth 客户端注册时   | **Dynamic Client Registration（DCR）**        |
| Client ID / Client Secret | 留空，由 DCR 自动注册                         |

Agent 连接使用 `/mcp`；账号与同步使用 `/cloud`。

## 3. 登录与授权

使用 ShowAI 账号密码，或已绑定该账号的 GitHub/Google 登录。第三方登录在新标签页完成，将显示的八位完成码复制回原始 ShowAI 授权标签页，再继续授权。所选第三方身份应已绑定到目标 ShowAI 账号。

可以授权一个已有项目，或「此账号当前和未来可访问的所有项目」。创建项目需要选择账号范围，并包含「项目创建」（`projects.create`）、读取与编辑权限。项目成员角色仍然生效，查看者无法写入。

公共组件、起始模板与临时渲染无需登录；私有项目操作需要授权。每个服务器账号使用自己的连接。

## 4. 创建和续改页面

新建对话，输入 `@` 并选择 **ShowAI**，例如：

> 列出我的 ShowAI 项目。创建「我的交互笔记」项目，制作一篇带可调示例的机会成本讲解，保存、确认同步，并在这里展示。

ChatGPT 提示写入时按界面检查。后续通过项目名、页面名或 ID 续改。Agent 读取当前源数据，用 hash/revision 保存，检查同步回执，再展示已保存页面。即使聊天只容纳局部预览，`page_present` 仍提供完整 HTML/source。

服务通过 `guide` 工具提供与本机插件同源的七条工作流程；这不会在 ChatGPT 中注册原生 Skill。宿主可能只先加载部分工具；指南列出所需工具时，在当前连接内继续发现。

## 更新与排查

| 情况                                 | 处理                                                  |
| ------------------------------------ | ----------------------------------------------------- |
| 服务或指南更新                       | 新建对话；后续调用使用已部署服务                      |
| 工具、参数、认证元数据或预览资源变化 | 在 Plugins 刷新 ShowAI 连接，再新建对话选择 `@ShowAI` |
| 登录过期或需要扩大项目范围           | 重新授权                                              |
| 找不到本地项目                       | 同步到同一服务器账号，并核对成员权限                  |
| 无法新建项目                         | 检查账号范围、`projects.create` 与服务器策略          |
| 第三方登录失败                       | 检查账号绑定，将完成码填回原始授权页                  |
| 预览失败或过期                       | 重新展示已保存页面，保留或下载完整 HTML/source        |
| 指南有工具名但未加载                 | 使用宿主工具发现机制，并限定当前连接                  |

HTTP 预览和下载链接有效期为一小时，项目中保存的页面是持续编辑的来源。保存成功与同步成功分别核对；同步有错误时应先处理再确认服务器发布。

此连接无需下载 ZIP。可分享本指南与 MCP 地址，每个人独立添加并授权。自部署见 [MCP 部署](cloud-mcp-deployment.zh-CN.md)，传输与权限见 [Agent 接入](agent-integration.zh-CN.md)。
