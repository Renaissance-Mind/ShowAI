# 内容库

**语言：** [English](../versioned-library.md) | 简体中文 · [文档目录](index.zh-CN.md)

ShowAI 用事务 SQLite 保存当前项目内容，并维护可读工作区、编辑草稿与可重建搜索索引。用户明确指定的项目优先于宿主目录解析。

## 存储约定

`history/content.sqlite` 是权威来源，目录名称保留兼容性。一次保存原子更新压缩内容对象、当前文件引用、资源并发 token 和操作回执，再通过持久恢复日志生成可读文件。旧对象只有在当前内容和保留原始档案都不再引用时才可回收。

页面元数据与稳定内容节点分别保存。data URL 二进制按摘要存入 assets，JSON 包装记录位置和 MIME；读取与导出重新组合完整文档。组件、模板、源码与编译包保留当前页面固定引用的精确依赖。

即使内容从 A 改到 B 再改回 A，资源 token 仍能识别变化。保存同时检查 hash 与 revision。operationId 标识同一请求，不能用于不同修改；较新编辑之后的重试需先重读当前内容。

## 读取与搜索

读取使用一致的当前数据库状态，协作写入等待。预览、阅读与 HTML 导出由已安装阅读器按需生成。

索引对应一个明确的当前状态，覆盖页面文字、嵌套容器、组件 props、包说明与源码。结果包含项目、资源、节点、位置、片段和索引 token。查询或索引状态改变会拒绝旧游标。索引不执行组件代码。

## 草稿与冲突

编辑器草稿以窗口身份、序列和原子代次持久保存，保留原始页面基线用于与当前内容比较。Agent 读取在有界缓存中保留可替换的会话/页面基线。独立字段可自动合并，有歧义的输入保留供检查。

事务失败保留传入修改。工作区外部文件变化先捕获再替换投影，并阻止受影响资源发布。包恢复产生可编辑草稿，经过真实编译和校验后发布新版本。编辑撤销/重做继续可用。

当前不提供页面内容历史浏览、历史预览或旧版本恢复。编辑撤销、保留的草稿/冲突和迁移原始材料各自用于对应恢复。page_diff 只比较仍保留的读取/草稿基线，缺失时返回 MISSING_BASELINE。

## 同步与维护

设备同步当前页面、精确组件依赖与资源，保留最后同步基线及并发/中断恢复输入；服务器以当前 token 条件发布。详见 [项目服务器与同步](project-sync.zh-CN.md)。

旧 Git 内容库在写锁下迁移，核对原始记录、字节和 ID 后激活，原始 Git 档案与旧 SQLite 记录继续保留。导入先保留源文件并验证当前页面、包与依赖。

容量统计区分内容对象、可读文件、索引、缓存、草稿、冲突和原始材料。压缩在写入租约下执行；经过检查的清理计划核对指纹与活跃引用，只删除符合条件的生成缓存。备份应包含当前内容和受保护恢复材料，不应只复制某个页面投影。
