# 可移植墨迹

**语言**　[English](../portable-ink.md) | 简体中文 · [文档目录](index.zh-CN.md)

新写入的钢笔和荧光笔笔迹是 `drawing` 节点，格式为 `attrs.ink.format = showai-ink-v2`。已有的 `showai-ink-v1` 节点沿用 v1 的解释规则。浏览器、Electron（含 Windows 构建）和 iOS 共用页面模型及带因果关系的墨迹操作。输入与几何计算使用同一套 C++ 源码，分别编译为 iOS 库和 WebAssembly。构建记录包含源码摘要和编译配置。各平台根据几何数据绘制，纹理和截图都可重新生成。

## 输入与几何

`showai-ink-v2` 用分段中心曲线保存笔迹。每段可以是点、直线、二次或三次曲线，并带有线性变化的半径。共享内核按照 `geometryVersion: 1` 和保存的 `outlineTolerance` 推导圆形笔尖扫过的轮廓。轮廓指令、覆盖区域、SVG、GPU 缓冲和纹理均可从源数据重建。支持圆头钢笔、荧光笔和等宽笔刷，遇到不支持的笔刷时报告错误。已有 v1 采样、遮罩、片段及归档按原格式读取。

`transform` 是仿射矩阵 `[a,b,c,d,tx,ty]`，`extent` 描述局部外框。页面布局在此基础上指定位置、缩放和旋转。浏览器在落笔时固定局部坐标系，收笔时将最终平移写入矩阵，保留原始输入和中心曲线。颜色、线宽、压感和布局可以分别调整。

可选的 `showai-input-capture-v1` 保存创建配置与全部已接收的真实采样。每条记录为 `[x,y,time,force,azimuth,altitude,id,expectedProperties,estimationIndex,updatesTimedOut]`。时间单位是秒，从首次真实接触起算。合并上报的点保留顺序与身份，预测点只更新临时笔尾，收笔前移除。浏览器保留触笔传感器的标准化压力值，鼠标和手指输入使用压力 1。浏览器的压力数值和原生 UITouch 有各自的标定。Pointer Events 提供同次接触期间的传感器修正，此时保留原位置和 ID；原生 Pencil 还可在收笔后更新估算值。

浏览器和 Electron 在专用 Worker 中运行 `CompiledInkInput` 和 `CompiledInkStroke`，保留输入内核的批次边界、所有压力变化节点和发生变化的末段。真实采样完整进入规范格式，旧式点列的 0.7 px 过滤和 20,000 点上限不适用于这条写入路径。每次真实接触立即占用独立的历史操作位置，保存与关闭会等待规范结果。后续界面操作可以独立进行，包括在上一笔完成前创建新对象。Worker 失败时会保留原始输入，供显式重试。

派生几何按每 128 个源曲段分块。整笔上限为 1,000,000 条指令和 100,000 个叶节点，每块消费端上限为 100,000 条指令。各块合并后只做一次透明度合成。Worker 和界面分别维护有上限的派生缓存。实际请求和结果共同绑定递归不可变的源、完整样式和推导参数，并据此验证几何。服务端渲染与独立阅读器共用同步的 C++/WebAssembly 内核，浏览器对编辑节点异步准备，独立 HTML 阅读器可直接运行。笔迹命中检测也使用共享几何。

v1 保留九字段采样、矢量遮罩、种子及可选的 `attrs.inkFragments`。关联片段共用一次选中、撤销和透明度处理。v2 校验会拒绝这些 v1 专用字段。超出容量或几何预算时会报告具体错误。相同内核保证对源数据的解释一致，GPU 抗锯齿效果和真机触笔延迟仍需分别实测。

## 原生场景

iPad 的原生相机和常驻 Metal 场景共同显示墨迹、形状，以及带版本的 Page 和组件纹理。书写、擦除、选择、拖动、缩放和惯性滚动在该场景中处理。相机移动复用已有几何；几何更新按顺序执行，可替换的相机请求可合并。富内容仍在共享工作台中编辑和排版。由原生场景绘制的墨迹和形状在网页层隐藏。

场景协议传递已确认版本、对象 ID、内容变化和当前姿态。接受一帧后才更新缓存。相机更新只传姿态。旧归档由 PencilKit 的公开 API 读取，新版原生 Board 的实时输入和渲染由 Metal 场景接管。

## 并发编辑与持久化

`showai-ink-operation-v1` 记录操作者、操作 ID、序号以及该操作已观察到的因果状态。几何、片段、元数据、颜色、线宽、压力、布局、放置关系和对象存续状态分别记录。独立字段的修改可合并，同一字段的并发值均保留为候选。解决冲突时，根据已观察到的当前分支写入新操作。旧快照不能清除尚未看到的远程修改或删除冲突。选择性撤销仅补偿满足条件的本地操作，保留其他操作者及并发分支的结果。

原生 JavaScriptCore 工作线程和共享应用使用相同版本的操作与传输模块。原生和桌面 SQLite 日志采用 WAL 和 FULL 同步。真实操作以事务提交，持久化成功后才回执；恢复时重放日志。稀疏投影只更新受影响对象。预测采样只用于当前显示。保存失败会保留待处理操作，过期回执不能覆盖较新的输入。

`showai-ink-state-v1` 在页面快照中保存因果状态和并发候选。设备间通过带 revision 条件的发布和三方页面合并传递状态，支持异步同步中的同时编辑。实时在线状态和逐笔触点流需要独立传输协议。

## 原生源数据与网页编辑器

`showai-native-source-v1` 信封标识完整且不可变的一次原生发布，范围由项目、页面、Board 和会话 token 确定。发布包含写入端最初读取的基线和历史操作。传输差异使用精确的 JSON 编辑，可表示数组中段的插入或删除。墨迹编辑使用上面的因果操作。一次真实保存成功后才前移传输基线。缓存未命中时展开最初捕获的完整发布，重试以该发布为准，后续尚未提交的编辑单独保留。

SourceRuntime 管理已登记的正文，私有传输对象、不可变的界面快照和可修改草稿分别持有数据。工作线程的规范化和精确的写时复制保留未知字段，并识别真实修改。存续的界面节点可复用独立持有的未改分支。判断相等需比较内容，保存回执只保存在会话元数据中。相同正文也可能对应新的历史操作，回执和历史按作用域内的操作 ID 去重。

iPad 的 GPU 与完整保存延迟仍需真机验证。准备工作已移出界面线程，当前测量以 iOS 仓库的验证记录为准。与 Notability 的书写体验也需单独比较。

## 迁移与兼容

`showai-pencilkit-v1` 旧归档通过 PencilKit 公开 API 转换为可编辑的规范笔迹，并保留原始归档供恢复。聚合节点的变换、分组与局部擦除结果均可继续编辑。可移植笔迹可以独立于原归档和 PNG 使用；旧浏览器的钢笔、荧光笔点列可适配为可移植表示。

共享新格式前，应将参与编辑的客户端一起升级。iOS 仓库固定共享源代码的提交和打包摘要。网站、Windows 与 macOS 安装包各自经过构建和发布后，还需在相应环境验证。

## 验证写入流程

`node scripts/test-portable-cubic-ui.mjs` 构建实际前端、Worker 和阅读器，并通过回环地址连接使用 FileStore 的真实工作台。它验证指针书写、保留源数据的样式修改与擦除、撤销与重做、冷启动重开，以及有待处理笔迹时离开、清空、销毁或切换页面。它还验证暂停真实 Worker 后创建新对象的情况、独立画布的本地恢复和离线矢量 HTML。桌面构建之后，`node scripts/portable-cubic-desktop-smoke.mjs` 验证 Electron 沙盒中的文件阅读器。已覆盖的平台与环境以各次测试记录为准。
