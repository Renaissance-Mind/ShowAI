# Page 与 Board

**语言：** [English](../page-surface.md) | 简体中文 · [文档目录](index.zh-CN.md)

Page 是**顺序排版的页面**，适合文档、报告和网页；Board 是**空间型白板**，支持平移、缩放、绘画与自由摆放。新建内容默认 Page，也可以直接创建 Board。两者都是原生容器，可以递归嵌套，展开后继续编辑**同一个节点**。

## 数据库项目

点击侧栏顶部的「新建数据库」，或在「添加」菜单中选择「新建数据库项目」。新建项目时也可以选择「数据库」类型。数据库始终作为独立项目创建，每条记录都是一个真实页面。点击文档名称或「新建文档」会从右侧展开编辑器，左侧数据库继续可操作。侧栏内可编辑标题、属性和正文，按当前视图的顺序查看上一份、下一份文档；可关闭侧栏、按 Esc 返回，或「全页打开」。页面改名后，数据库中的名称同步更新。

顶部可切换表格、看板和列表，也可添加、改名或删除视图。各视图独立保存筛选、排序和看板分组设置；当前选中的视图按本机内容库和数据库记忆。看板按单选属性分组，在卡片上更改该属性即可移动分组。删除视图保留文档与属性，至少保留一个视图；旧数据库会自动提供默认视图。

数据库项目在标题与视图栏之间有独立的内容区。点击「添加文字、标题或列表…」即可使用原生编辑器编写介绍、说明和列表，也可以用 `/` 插入常用内容。内容自动保存，切换表格、看板或列表时共用同一份介绍；已有数据库初始为空，普通项目不会显示这个入口。介绍与文档属性分别保存，同一段介绍发生并发编辑时可在现有冲突提示中选择保留内容。

属性支持文本、数字、单选、日期、复选框和链接。在最后一列标题旁点击「添加属性」，就近填写名称并选择类型，确认后生成新列；取消不会创建属性。「属性设置」中也可使用同一表单，并管理已有列。拖动表格属性标题，或「属性设置」中各行左侧的手柄，可以调整顺序；拖动整列或整行时，相邻属性实时让位，松手后归位并保存，Esc 可取消预览。表格、其他视图与右侧文档共用该顺序，文档名称固定在首列。顺序支持撤销和重做；也可用 Alt+Shift 加相应方向键移动属性。在表格中编辑单元格，点击列名排序，使用搜索或等值筛选查找记录。属性自动保存；同一属性发生并发修改时，可以选择保留的值。删除记录沿用页面删除确认，属性数据随归档页面保留。

记录可以在本项目内整理。在支持属性迁移之前，跨项目移动数据库记录或其所在文件夹会被拦截。

## 插入与编辑

Page 和 Board 与 Markdown、图片、图表等一起列在组件库中，支持搜索、预览和插入。编辑区使用 `/` 菜单直接搜索并插入所有组件；Page 和 Board 插在光标所在位置，前后文字与嵌套位置保持完整。白板空白处按 `/` 使用同一组件目录，页面末尾可继续在普通空白段落输入。新增内容不再提供顺序、网格、自由分组三种独立菜单项；已有分组继续可编辑和调整布局。

## 内容与外框

**父级决定模块的位置和外框，子容器决定内部布局**。Page 的子节点按内容顺序排列，Board 的子节点使用相对所属容器的坐标。流式、网格和自由分组仍使用 `region`，分组自身不创建新的视口。

Page 中的 Board 默认使用固定高度窗口，内部绘画不会撑开文章。Board 中的 Page 默认使用固定阅读窗口，可以在其中上下阅读，也可以展开。Page 外框可在模块设置中改为随内容增长。

Page 的正文、文本模块与流式内容区域共用一个文档编辑器，光标、文字选择和键盘导航可连续穿过这些内容。文本区域保留原有身份与内容结构，正文不显示白板对象外框或常驻模块标题栏。嵌套容器与网格、自由布局作为文档中的组件呈现。

正文与插入组件使用相同的外框规则：悬停或选中内容都不增加外框，Markdown、图片、图表、媒体、绘画和嵌套容器均按此规则显示。选中状态仍用于现有菜单、手柄和键盘操作。容器本身的边界、图形自身的线条、文字选区和表格单元格选区继续表达各自的内容与操作状态。

### 内容层级与撤销

工作区顶部的内容层级显示当前展开路径。「返回上层」恢复父级视图。通过外框手柄移动整个模块，通过文字或内部控件编辑内容。所有层级**共享一个资源文件、保存机制和编辑撤销记录**；跨容器移动、删除、绘画和包裹都可以撤销。

## Page 原生目录

通过「页面操作 → 目录设置」为当前 Page 启用目录。未启用时，页面没有目录入口和占位。默认阅读索引跟随原生标题，支持收录深度、显示名覆盖与隐藏条目，并以嵌套容器为作用域边界。手动目录可以创建分组、选择正文目标、调整顺序与缩进；修改目录顺序不会移动正文。

标准和加宽页面会测量正文旁的实际留白，空间足够时使用页边目录，否则使用浮动目录。全宽页面使用浮动目录。读者可以收起、展开或固定目录；窄屏使用抽屉，定位章节后自动收起。个人阅读状态按页面视图独立保留，不修改页面内容。独立 HTML 包含导航、目录组件和页面宽度设置；打印使用简明的语义目录。

配置保存在对应 Page surface 的 `attrs.outline`：

```json
{
  "version": 1,
  "enabled": true,
  "source": { "mode": "headings", "maxLevel": 3 },
  "initialState": "auto",
  "placement": "auto",
  "width": 220
}
```

`initialState` 支持 `auto`、`expanded`、`collapsed`；`placement` 支持 `auto`、`floating`、`docked`；宽度范围为 180–480px。`enabled:false` 关闭目录并保留配置，删除属性则移除配置。标题覆盖使用 `source.overrides: {"标题ID": {"title":"显示名", "hidden":false}}`。手动来源使用 `{mode:"manual",entries:[{id,title?,nodeId?,children?}]}`；无跳转目标的分组需有名称。失效引用可在设置中修复，阅读导航会跳过失效目标。

### 自定义目录组件

目录组件在 manifest 中声明 `role:"page-outline"`、`pageOutlineProtocol:1` 和 `category:"outline"`，复用现有组件的源码、参数 schema、精确版本、编译及沙箱机制。组件库提供「页面目录」分类。通过目录设置选择组件，或把 `{componentId,version,integrity,props}` 写入 `attrs.outline.renderer`；模板复制和离线导出会携带确定版本。省略 renderer 使用内置阅读索引；组件不可用时，显示恢复提示和基础目录。

React 入口接收以下数据与操作：

```ts
{
  props, // 作者保存的参数，按组件自己的 schema 校验
  outline: {
    protocol: 1, pageId,
    items: [{ id, title, level, navigable, children }],
    activeItemId, expandedItemIds,
    container: { placement, width, height },
    theme, locale
  },
  navigate(itemId),
  setBranchExpanded(itemId, expanded),
  collapse()
}
```

组件可以自行设计列表、树或图形导航，在给定空间中绘制，保持键盘、触屏、当前章节与分支展开状态可达。宿主校验条目身份并执行导航；只读页面也保留这些操作。作者参数、生成的目录树和个人分支状态分别管理。整体收起控件由宿主提供。动作协议同时支持独立沙箱阅读器和对话内联阅读器。

`examples/page-outline-index` 与 `examples/page-outline-path` 是两份完整的可导入实现。例如执行 `showai catalog import --project PROJECT --input examples/page-outline-index --json`，再到 Page 目录设置中选用。Agent 可通过当前 hash / revision 下的 `block.attrs.set` 修改 Page 目录属性。

## 交互

| 操作                              | 行为                                     |
| --------------------------------- | ---------------------------------------- |
| 阅读 Page                         | 原生纵向滚动、文字选择、键盘与输入法     |
| 在锁定的 Board 模块上滚动         | 继续阅读外层 Page，内部视图保持位置      |
| 点击右上角的锁定图标              | 切换锁定状态，解锁后可缩放、平移和绘画   |
| 阅读 Board 左右滑动               | 可见弹性阻力，手势停止后回弹或轻微吸附   |
| 编辑 Board 滚动、拖动画布         | 1:1 跟手平移，不吸附、不回弹             |
| 中键、空格或移动画布工具（M）拖动 | 平移；编辑文字时空格用于输入             |
| Board 空白处拖动                  | 框选                                     |
| Board 捏合、Ctrl/Command + 滚轮   | 围绕指针缩放（10%–400%），之后不漂移     |
| 画笔、矩形、椭圆、箭头            | 在所属 Board 的本地坐标中创建绘画节点    |
| 外框展开                          | 在更大工作区编辑同一节点，保留归属和 ID  |
| Escape                            | 先取消当前绘画/操作，再退出当前层级      |
| 撤销、重做                        | 恢复内容和结构；元数据与个人视图独立处理 |
| 放入 Page / 放入 Board            | 增加对应外层容器，原节点成为其子节点     |

### Board 编辑

- **选择与移动**：单击对象选中并显示外框，按住对象任意位置拖动即移动；再次单击已选文字进入编辑，回车也可进入，Escape 退出编辑并保持选中。已选组件的点击交给组件自身。多选显示一组整体手柄，单击其中一个对象可收窄选择。
- **修饰键**：Shift 拖动锁定水平或垂直方向；Alt 拖动复制后移动副本；Alt 调整尺寸以中心为基准；Command/Ctrl 关闭吸附。绘制图形时 Shift 约束比例，Alt 从中心绘制。
- **工具与位置**：工具栏可拖到画布上、下、左、右边缘停靠，位置保存在本机；选中对象后，复制、层级、对齐与分布、放入区域、锁定和删除出现在工具栏的选中区，弹出菜单朝画布一侧展开。拖到视口边缘或在拖动中滚动滚轮会平移画布。双击空白处或用文字工具单击写文字；绘制后保留当前工具，不自动选中刚画的对象。
- **区域**：绘制的区域会收入完全落在其中的对象；区域空白内部不遮挡下方对象，可从边框或空白处选中并拖动区域。
- **小地图**：整页 Board 的工具栏可打开小地图，单击或拖动跳转；开关保存在本机。

锁定对象保存为 `layout[id].locked: true`：不能拖动、缩放或被框选，仍可单击选中、从菜单或快捷键解锁。

嵌套的 Page、Board、表格、代码区和组件拥有明确的输入边界。已开始的手势由同一层处理到结束。自定义组件可通过 `GestureBoundary` 声明所需的轴；iframe 内部继续由其自身接收事件。

### 阅读锁

整页 Board 与展开后的 Board 工作区始终可操作，不提供阅读锁。嵌入的 Board 与流程图右上角提供阅读锁，首次显示时**默认锁定**。锁定时禁止缩放、平移、节点拖动和改变视图的拖拽手势，点击、右键、提示、内容展开和编辑控件继续工作。解锁后恢复对应的浏览与拖动功能。

G2 图表根据实际绘制配置决定是否显示阅读锁：开启框选筛选、框选高亮、滑块筛选、滚动条筛选或鱼眼交互时显示。只有提示、悬停高亮或图例点击的图表不显示锁，也不接管外层白板的滚动手势。默认的 43 种 G2 图表均未配置需要阅读锁的交互；开启框选后，锁定会禁用框选，解锁恢复该交互。

组件的锁定状态保存在本机个人视图存储中，重开页面或从展开视图返回后恢复。沙盒组件由宿主保存状态并转交阅读滚动。独立导出的不透明沙盒无法使用持久存储时仍可临时切换，图标提示保存失败。

### 动效与手势

白板动效沿用连续的阻力和阻尼弹簧，可以被新输入打断。减少动态效果偏好保留跟手位移，直接完成回位。绘画的指针捕获与白板平移分开，绘画期间不会同时移动相机。

## 版本 3 模型

```json
{
  "format": "showai",
  "version": 3,
  "document": {
    "id": "research",
    "title": "研究报告",
    "content": {
      "type": "surface",
      "attrs": { "id": "report", "kind": "page", "name": "报告" },
      "content": [
        {
          "type": "paragraph",
          "attrs": { "id": "intro" },
          "content": [{ "type": "text", "text": "问题、材料与解释。" }]
        },
        {
          "type": "surface",
          "attrs": { "id": "analysis", "kind": "board", "name": "分析白板" },
          "content": [
            {
              "type": "surface",
              "attrs": { "id": "evidence", "kind": "page", "name": "详细论证" },
              "content": [
                {
                  "type": "paragraph",
                  "attrs": { "id": "detail" },
                  "content": [{ "type": "text", "text": "这里继续顺序阅读。" }]
                }
              ]
            }
          ]
        }
      ]
    },
    "layout": {
      "analysis": {
        "x": 0,
        "y": 0,
        "width": 800,
        "height": 460,
        "heightMode": "fixed"
      },
      "evidence": {
        "x": 80,
        "y": 60,
        "width": 600,
        "height": 380,
        "heightMode": "fixed"
      }
    },
    "surfaceViews": {
      "report": {
        "initial": null,
        "saved": [],
        "readingOrder": ["intro", "analysis"]
      },
      "analysis": {
        "initial": null,
        "saved": [],
        "readingOrder": ["evidence"]
      },
      "evidence": { "initial": null, "saved": [], "readingOrder": ["detail"] }
    }
  }
}
```

包括根容器在内的非文本节点具有**唯一稳定 ID**。`surface.attrs.kind` 为 `page` 或 `board`。`layout` 保存父级赋予子节点的外框；根容器没有父级外框。位置范围为 ±1,000,000，普通模块宽度 120–10,000；绘画节点可以更小。`heightMode: auto` 只适用于 Page。分组的 `mode`、`columns`、`gap` 保持 flow/grid/free 约定。

`surfaceViews` 按容器 ID 保存命名视图、初始视图和阅读顺序。视图目标必须属于该容器。Page 的阅读顺序就是内容树顺序；Board 的阅读顺序供线性导出使用。个人滚动、相机、选择和展开状态保存在本机，**不改变内容 hash**。

绘画节点使用 `drawing`，属性包含 `tool`、六位十六进制 `color`、`strokeWidth`、`extent: [width,height]` 和本地 `points: [{x,y}]`。其位置和显示尺寸仍在 `layout` 中，放大缩小父级不会改写笔画点位。

`layout.rotation` 以角度表示绕对象中心的旋转，范围 −360 到 360。图像和非箭头绘画支持旋转；Page、Board 和交互组件保持正向。内容自动决定高度的对象可以带 `contentSize: {width,height}`，它记录上一次编辑时的实测尺寸，只在对应宽度下参与几何计算，不设置 CSS 高度。阅读器会重新测量当前内容并更新连接显示，纯阅读不会保存这些测量值。

箭头可增加 `attrs.bindings.start` 和 `attrs.bindings.end`，各自为 `{targetId,anchor:{x,y}}`。锚点坐标为目标未旋转外框中的 0–1 比例；目标必须与箭头同级且具有外框，父容器为 Board 或自由布局 region，且不能是另一条箭头。目标移动、改变尺寸或旋转时，连接端点随之更新。删除目标或把目标移入另一父容器会把对应端点保留为自由端点；撤销恢复原关系。移动整个 Page/Board 不改变它内部节点的局部坐标与绑定。自由区域切换为 flow/grid 时，直接子对象改按新排列呈现，直接箭头子节点的绑定和直接子对象的旋转会解除；嵌套 Board 或自由 region 的内部几何保持原样。箭头保留为绘画项；撤销恢复原局部布局与关系。

单独对箭头执行 `surface.layout.set` 会解除绑定；同一批操作中同时变换箭头与目标时，保留它们之间的绑定。相同数值的更新不解除绑定。完整文档写入以显式提供的绑定为准，清除绑定才能把端点变为自由点。模板复制同步映射内部目标 ID；局部导出把指向未导出对象的端点保留为自由点。编辑中的一次拖动、尺寸调整或旋转对应一次撤销，尺寸测量回写归入同一次编辑。

## Agent、模板与导出

`showai guide containers --json` 提供完整约定。新建可用 `pages create --kind page|board`。插入组件使用 `component.insert`，Page/Board 与普通组件共用同一入口；原生容器仍保存为 surface 节点。`surface.create` 在指定父级加入容器；`surface.wrap` 包裹当前根或某个容器；通用区块操作保留内容身份。视图操作通过 `surfaceId` 定位所有者，省略时作用于根。受控修改始终要求当前 base hash。

模板完整保存嵌套树、外框和各层视图。实例化时一起重建所有身份及引用，加入现有页面时作为原生模块插入。局部导出可以选择任意容器，包含其后代和必要祖先；源资源保持原样。

独立网页保留 Page 阅读、Board 浏览和逐层展开。`--presentation reading` 将所选根 Board 按阅读顺序呈现。打印保留嵌入 Board 的空间关系并适配可打印宽度；Board 中的 Page 保留外框窗口，可单独选择该 Page 导出完整阅读内容。会话片段超过体积预算时会压缩阅读器代码，源 JSON 仍保持完整明文；解压和运行均在本机完成，总体积限制保持不变。

## 兼容

v1 文档在内存中映射为 Page，旧画布块转换为其中的 Board 组件，前后正文保留原顺序。v2 的单一流式文本区域按 Page 编辑；其他空间布局作为嵌入 Board 保留坐标、内容身份和视图。版本 3 中明确创建的 Page 与 Board 保持类型。**读取不会重写文件**。首次受控保存到新版本时，在 `migrations/<resource-id>/original-v1.json` 或 `original-v2.json` 保存原始字节，并保留历史快照。已迁移资源不允许用较旧格式直接覆盖。
