# 行为准则

**语言：** [English](../../CODE_OF_CONDUCT.md) | 简体中文

ShowAI 遵循 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) 的精神，欢迎不同背景与身份的参与者，维护尊重、友好且无骚扰的协作环境。

## 期望行为

- 友善、耐心，善意理解他人。
- 围绕工作给予和接受建设性反馈。
- 尊重不同观点、经验与语言，欢迎中英文讨论。
- 为错误负责，并从中学习。

## 不可接受的行为

- 骚扰、侮辱、人身或政治攻击。
- 性暗示语言、图像或不受欢迎的关注。
- 未经允许公开他人隐私。
- 持续干扰、挑衅或不符合专业环境的行为。

## 范围

适用于项目的 Issue、Pull Request、讨论，以及代表项目参与的任何渠道。

## 报告与处理

请向 **caopu@bupt.edu.cn** 报告问题。报告私下处理，保护报告者身份。

维护者可移除、编辑或拒绝违反准则的评论、提交、代码等贡献，并依严重程度和行为模式采取警告、临时限制或永久禁止参与。
