# ShowAI 内置 Agent

**语言：** [English](../agent-host.md) | 简体中文 · [文档目录](index.zh-CN.md)

在页面中通过选中文字、内容块菜单或白板对象菜单选择「让 AI 处理」，也可从顶栏打开项目对话。设置中的 Agent 页面配置执行位置、本机 Agent 与模型来源。所有执行路径使用项目绑定 MCP 与当前 hash/revision。

## iPad 与远程执行

iPad 在 AI 面板和「设置 → Agent」中选择服务器账号及运行位置。云端执行可以直接配置用户自己的 LLM API，也可以从服务器模型资源中选择已有来源。使用 ChatGPT 套餐时，先在 Mac 的 Agent 设置完成官方授权，将来源发布到自己的 ShowAI 服务器，再在 iPad 的服务器模型来源中添加；OpenAI 的 OSS 授权使用本机回调。发布后由服务器统一保管加密凭据并刷新授权，同一账号的云端 Agent 可以直接选用。

使用自己的 Mac 时，在该 Mac 的「设置 → Agent → 让 iPad 使用这台电脑」中开启远程执行，选择服务器账号和允许访问的同步项目。Mac 主动通过 WSS 连接 ShowAI Cloud。iPad 使用同一个服务器账号，选择在线的 Mac；首次请求需要在 Mac 上确认设备，之后可以随时撤销。Mac 使用本机已有的 Agent 配置与登录，执行期间保持 ShowAI 运行、电脑唤醒且网络可用。

各执行位置的模型来源与设置独立。发送前先保存并同步当前页面，若同步期间页面发生变化则要求检查最新内容。每段对话绑定其执行设备和账号；执行记录、取消、审批、附件读取和撤销均沿用该绑定。任务在页面发布完成后才报告完成，设备断线或同步失败显示实际原因。

Cloudflare 执行服务使用 Worker、Durable Object、按账号隔离的 Container 和加密 R2 检查点。部署入口为 `node scripts/deploy-remote-agent.mjs <私有发布目录> [已提交版本]`，它导出提交后构建，保留已有状态密钥，并生成发布回执。密钥备份和发布目录只保存在部署者本机。重新部署必须保留原有密钥与状态桶。

内置 Agent 在页面中使用：选中文字、打开内容块菜单或右键白板对象，选择**让 AI 处理**；页面顶栏的 AI 按钮打开项目的对话记录。设置中的 Agent 页面只配置执行方式、本机 Agent 与模型来源。两种执行方式都通过**项目绑定的 MCP** 复用 ShowAI 的项目工具，页面读写继续使用**当前 hash 和 revision**，并保留内容库现有的保存冲突处理。

| 方式         | 运行时                                                    | 凭据与能力                                                                          |
| ------------ | --------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| 本机 Agent   | 已安装的 Codex、Kimi、Claude Code、Gemini CLI 或 OpenCode | 复用该 Agent 的本机登录；探测程序与认证状态，真实调用测试单独记录                   |
| 提供 LLM API | 按需安装的官方 Codex TypeScript SDK 与对应平台运行时      | ShowAI 管理模型来源，运行时只安装 ShowAI 插件并使用独立 HOME、CODEX_HOME 和会话目录 |

本机 Codex 使用新的任务会话，不接管桌面上已有的对话。Kimi、Gemini 和 OpenCode 通过 ACP 连接；需要用户确认的 ACP 工具请求在对话中显示，允许一次或拒绝。Claude Code 使用其非交互接口。没有找到程序或调用失败时，界面显示实际原因，配置文件存在不代表调用已通过。

## 页面中的对话

| 入口                             | 作用对象             |
| -------------------------------- | -------------------- |
| 选中文字或表格单元格后的格式菜单 | 选中文字与所在内容块 |
| 内容块把手菜单                   | 该内容块             |
| 白板选中工具栏、对象右键菜单     | 选中的白板对象       |
| AI 面板输入框                    | 当前页面             |

请求框提供润色、精简、扩写、翻译、可视化和解释等快捷操作，也可以直接输入要求。发送前先保存当前页面，Agent 读取的就是界面中的内容。宿主把页面与稳定的块 ID、选中文字一起告诉 Agent，要求先按块读取，只修改这些对象；解释类请求只在对话中回答。

对话按项目保存，每一轮记录完整请求、作用对象、执行过程和页面结果。执行期间页面不锁定；Agent 的保存与其他外部修改一样：没有本地未保存修改时直接载入；有独立修改时通过三方合并继续保存，双方改到同处时保留草稿并显示冲突。每轮结束后可以定位 Agent 实际修改的对象。撤销根据本轮工具的真实写入记录恢复，保留首次写入前已经保存的人工修改；多次写入之间或最后写入之后出现其他修改时，会拒绝整页撤销。没有写入记录的旧对话无法直接撤销。

对话的执行方式在创建时确定。提供 LLM API、本机 Codex 和 Claude Code 续接同一底层会话；Kimi、Gemini 和 OpenCode 每轮新建会话，宿主把前几轮摘要附在请求中，并在对话里注明。只读页面、阅读器和导出页面不显示 AI 入口。

## 模型来源

预设包括 ChatGPT 套餐、OpenRouter、DeepSeek、OpenAI API、Moonshot 和自定义服务。Responses 来源直接转发 Responses 请求；Chat Completions 来源通过任务专属的本机网关转换输入、命名空间工具、工具结果和流式完成事件。具体模型仍需通过**真实调用确认兼容性**。

API Key 与 OAuth 凭据存放在应用专属目录，文件权限为**仅当前用户可读写**，设置响应只返回连接状态。

模型供应商凭据由网关读取；Codex 子进程只取得本机网关的任务凭据。网关绑定 127.0.0.1，任务结束后关闭。ChatGPT 使用官方动态注册、PKCE、state、nonce 与 ID token 验证流程；只向官方 Responses API 使用这类授权。

### 安装与更新

SDK 和平台包从官方 npm 注册表获取，核对 SHA-512 完整性后解包，不执行安装脚本。安装不写入全局 npm、Python 或用户的 Codex 目录。ShowAI 插件通过独立 Codex 的官方插件命令安装，安装后检查插件与可见 Skill 清单。升级完成前保持旧安装记录；失败会显示具体原因。

## 执行位置与权限

桌面运行时和凭据位于 Electron userData 下的 agent-host 目录。任务工作区默认位于文档目录的 ShowAI/Agent Workspaces，按项目与任务分开。页面通过 ShowAI 工具写入原项目；工作区保存辅助材料与中间文件。

对话记录保存在 agent-host 目录下的 `conversations/<项目>/`，执行过程中持续写入；每轮发送前的页面版本另存一份，用于撤销本轮。每个对话使用一个固定工作区，本机 Agent 的会话按工作区续接。开发实例可用 `SHOWAI_AGENT_WORKSPACES` 指定工作区根目录。

SDK 子进程使用**独立环境**，不继承用户的 API Key、Codex 登录令牌、宿主会话 ID、skills 或插件配置。ShowAI 的页面创建、保存、局部修改、组件与模板创作工具在项目绑定的连接中授权执行；其他工具保留自身的审批行为。命令执行使用 workspace-write 沙盒。

本机 Agent 模式保留其已有认证与运行配置。连接测试发送一条简短请求，不修改页面；**只有收到实际完成结果**才显示调用通过。任务的模型来源固定在启动时，继续会话必须属于**同一项目和来源**。

## 项目绑定与展示

内置 Agent 的宿主显式提供项目 MCP。其私有插件副本保留七个 Skill，移除外部插件的 library MCP 启动配置，避免同时接入整个内容库。连接失败时不改用创作 CLI 或另一个项目。

**保存页面后**使用 `page_present` 返回完整 HTML/source 和可选 inline 预览。当前内置聊天按文字与文件链接交付；它不因生成 inline 就具备对话 HTML 显示能力。文件路径由运行时分配，读取和保存沿用当前项目身份、hash/revision。

## 局域网配对与协作画布

Mac 在设置 → Agent 中开启「让 iPad 使用这台电脑」，选择服务器账号和允许访问的同步项目；iPad 点击「配对附近的 Mac」。核对两端相同的六位数字后，在 Mac 确认，无需二维码。记住的设备固定校验证书和设备凭据并自动重连；撤销授权或身份变化后重新配对。Mac 使用本机模型配置与登录，局域网外继续支持现有 WSS 远程执行通道。

启用 Mac 代存的项目在 iPad 保留持久副本与待传修改，经固定证书校验的 TLS 连接提交页面，Mac 通过 WSS 通知内容更新并继续服务器同步。独立修改自动合并，同处修改保留并显示冲突。断联时继续保存到 iPad，重连补传；「断开并恢复服务器同步」保留待传内容并恢复原有路径。云端任务启动前需确认 Mac 已将当前内容同步服务器。

Agent 运行时画布可继续编辑。每个对话保留独立输入草稿和目标，工具更新合并进同一条进度记录。发送框旁的「标记参考位置」支持画布点或区域，作为 prompt 建议。Board 上新插入的普通组件进入可编辑 Page，相关组件可共用 Page；`attrs.frameless:true` 去掉外框。协作与未提交内容的边界见 [协作画布 Skill](../../plugins/showai/skills/collaborate-canvas/SKILL.md)。
