# Page 白板

每个 Page 都是一块白板。区域、文字、图片和组件是平等的内容节点；区域提供纵向流、网格或自由布局。阅读文章、并排对照、组织图表都在同一空间完成。最初的区域可以移动、替换或删除，空白 Page 和仅含图片、组件的 Page 也有效。

白板采用白色底面，内容延续同一背景。标题属于页面元数据，可另行放入内容中的标题区块。区域标题和编辑控件按需显示。

## 操作与手势

| 操作                            | 效果                                                 |
| ------------------------------- | ---------------------------------------------------- |
| 上下滚动                        | 长内容顺畅阅读，越过可读范围时出现弹性位移           |
| 左右滑动、Shift + 滚轮          | 带动内容产生横向阻力；吸附处轻滑回弹，持续滑动可离开 |
| 拖动空白处、鼠标中键拖动        | 平移白板，沿用阻力和吸附规则                         |
| 工作区聚焦时空格 + 拖动         | 平移；文字输入时空格保持输入用途                     |
| 触控板捏合、Ctrl/Command + 滚轮 | 围绕指针缩放，范围 25%–200%                          |
| 双指触摸                        | 平移和缩放                                           |
| 总览、Home 或 0                 | 定位全部内容                                         |
| 定位所选                        | 定位当前所选节点                                     |
| 区域与视图目录                  | 定位区域、保存命名视图、指定初始视图和阅读顺序       |
| 添加内容                        | 创建流式、网格、自由区域、独立文本或图片             |
| 区域设置                        | 调整布局、网格列数、名称、所属区域和顺序             |
| 文字块菜单 → 移出区域           | 保留块身份，将内容放入区域外的白板                   |
| 内容标题栏、宽度手柄            | 拖动移动或调宽；方向键微调，Shift 加速               |
| Escape                          | 取消进行中的拖动或导航，关闭当前选择                 |
| 删除后撤销删除                  | 恢复最近删除的节点、布局和相关视图引用               |

完整或接近完整显示的区域可以建立轻微吸附。吸附处的小幅输入立即产生可见偏移，手势停止后逐帧回弹；长区域在纵向可读范围内保持自由阅读。连续累计拉动超过 240 屏幕像素可以脱离锚点。相邻区域遵循同一规则。新输入从当下显示的位置接续，可以打断弹簧回弹和定位动画。减少动态效果偏好保留跟手位移，直接完成回位。

表格、代码滚动区、输入控件和 iframe 优先处理自己的手势。组件可从 `showai:components` 导入 `GestureBoundary`，用 `axes={["x"]}`、`["y"]` 或 `["zoom"]` 声明需要的轴。底层兼容 `data-surface-gesture="x y zoom"` 和完整接管的 `"own"`。文字编辑、框选和输入法组合期间不会触发空格平移。

## 共享内容模型

`.showai.json` 的版本 2 使用 `surface` 根节点，`region` 或独立内容位于其下。区域可以嵌套区域；`richText` 保存连续的富文本编辑片段。原有段落、列表、表格和组件节点继续作为内容使用。

```json
{
  "format": "showai",
  "version": 2,
  "document": {
    "id": "comparison",
    "title": "研究对照",
    "content": {
      "type": "surface",
      "content": [
        {
          "type": "region",
          "attrs": { "id": "article", "name": "研究说明" },
          "content": [
            {
              "type": "paragraph",
              "attrs": { "id": "intro" },
              "content": [{ "type": "text", "text": "研究问题与材料。" }]
            }
          ]
        }
      ]
    },
    "layout": {
      "article": {
        "x": 0,
        "y": 0,
        "width": 920,
        "mode": "flow",
        "columns": 2,
        "gap": 24
      }
    },
    "views": { "initial": null, "saved": [], "readingOrder": ["article"] }
  }
}
```

内容树决定归属。`layout` 按稳定节点 ID 保存空间位置和区域布局；坐标使用父级内的 CSS 像素，与缩放无关。根节点及自由区域内的直接子节点按坐标定位，流式与网格区域按内容顺序排布。`height` 是最小高度，内容增高时不会被裁切。坐标范围 ±1,000,000，宽度 120–10,000，最小高度 40–1,000,000；区域列数 1–12、间隔 0–160。

`views.saved` 存放 `{id, name, targets}`，目标可以是区域或其内部区块。`initial` 引用默认命名视图，`readingOrder` 指定根节点阅读顺序。删除、重排和模板实例化同步处理这些引用；无效外部文件会明确报错。个人相机位置保存在本机，不触发页面保存、撤销或内容 hash 变化。重开时优先恢复有效个人位置，其次初始视图和第一个有效节点；删除旧锚点后会恢复有效内容。

## 编辑、模板、Agent 与导出

编辑器和阅读器使用共同的区域渲染器、坐标变换和导航。区域内的原生编辑器保留文字选择、键盘和输入法体验。视口移动逐帧更新变换；未出现的区域延后挂载，需要定位、总览和打印时先加载目标内容。

Agent 使用 `guide whiteboard` 获取模型说明。`block.insert/move/replace/remove` 操作内容树；`surface.layout.set` 修改位置和布局；`surface.view.save/remove` 管理命名视图；`surface.reading-order.set` 调整阅读顺序。`surface.upgrade` 显式迁移旧页。所有受控写入沿用 base hash、冲突检测和快照。

模板保存内容、布局和视图。创建新页面或加入现有白板时，一起重建节点 ID、布局键和视图引用。组合模板可以包含旧版内容或白板结构，展开后形成同一白板。加入现有页面支持指定目标区域，保留目标页面的初始视图。

HTML、inline 和网站默认采用空间呈现。`--presentation reading` 按阅读顺序生成响应式页面，区域内部继续保留内容顺序和网格排布。打印和 Markdown 使用阅读顺序；导出的可编辑源始终保留完整空间结构。

## 旧页与发行版本

版本 1 的 `doc` 页面可直接读取。编辑器在内存中将原有正文和 `attrs.canvas` 内容转为普通区域；原始标题保留为区域内标题，已有合法 ID 保留。旧文件中的重复或保留 ID 会确定性地重建。首次受控保存为版本 2 时，Core 在 `migrations/<page-id>/original-v1.json` 保存原始字节，已有快照保留。读取和导出不会自动改写原文件。

桌面、运行包和本地浏览器包记录应用版本、Page 模型版本、源码 commit 和前端文件摘要。桌面打包检查运行包与 App 前端一致。应从干净提交构建，并在实际发行包上验收；版本号相同本身不代表内部资源一致。

视口坐标和指针中心缩放的处理参考 [cowrite-surface](https://github.com/caopulan/cowrite-surface/tree/790c11890a2d413c698076acce80ca3ef14aac29)。
