# 统一白板

页面中的正文、图表和独立内容块共享同一块白板。浏览、缩放、添加内容和回到正文始终使用相同的工具栏。白板与内容区域采用一致的页面底色。

横向滑动会立即带动内容，以柔和阻力跟随手势。当某个内容区域完整可见或接近完整可见时，视口会轻微吸附。吸附后的小幅滑动形成可见的弹性偏移，松手时通过连续的弹簧动画回到原位。持续拉动可以离开吸附位置，区域之间的横向移动也保留阻尼。

## 操作

| 操作                            | 效果                                                 |
| ------------------------------- | ---------------------------------------------------- |
| 上下滚动                        | 在当前内容区域中顺畅阅读，越过边缘时产生弹性位移     |
| 左右滑动、Shift + 滚轮          | 带动内容产生横向阻力；吸附处轻滑回弹，持续滑动可离开 |
| 拖动空白处、鼠标中键拖动        | 在白板上平移，使用同一套阻力和吸附规则               |
| 工作区聚焦时按住空格并拖动      | 平移视口；输入文字时空格保持输入用途                 |
| 触控板捏合、Ctrl/Command + 滚轮 | 围绕指针缩放，范围 25%–200%                          |
| 双指触摸                        | 平移和缩放                                           |
| 「回到正文」或工作区中的 Escape | 平滑回到正文，保留纵向阅读位置                       |
| 「总览画布内容」                | 缩小并定位正文与独立内容，最低缩放 25%               |
| 「添加内容」                    | 添加支持文字、图片、图表及既有区块的独立内容区域     |
| 正文区块菜单 →「移至画布」      | 将原有区块移到正文旁边，保留区块 ID                  |
| 独立内容标题栏、右下角          | 拖动移动或调宽；方向键微调，Shift 加速               |
| 「收回正文」                    | 将独立内容移到正文末尾                               |
| 删除后「撤销删除」              | 在当前页面会话中恢复最近删除的内容区域               |

吸附只做小幅位置调整。接近居中的区域会轻轻对齐，已经完整可见但偏离中心的区域会保持当前位置并建立阻力锚点。正文与独立内容使用相同的计算方式。长内容在区域内部可以连续纵向阅读。

表格、代码滚动区域、滑块、下拉菜单和嵌入组件优先接收自己的手势。自定义组件可以用 `data-surface-gesture="own"` 声明自行处理手势。iframe 内部事件由其自身内容接收。

## 内容模型

独立内容使用现有 `callout` 容器，位于 `document.content.content` 顶层。空间信息存放在 `attrs.canvas`，容器内仍使用现有区块结构：

```json
{
  "type": "callout",
  "attrs": {
    "id": "canvas-note-1",
    "icon": "",
    "tone": "neutral",
    "canvas": { "x": 1064, "y": 120, "width": 360 }
  },
  "content": [
    {
      "type": "paragraph",
      "attrs": { "id": "note-text-1" },
      "content": [{ "type": "text", "text": "相关材料与补充说明" }]
    }
  ]
}
```

坐标使用相对于正文左上角的 CSS 像素，与当前缩放无关。`x`、`y` 必须是 ±1,000,000 范围内的有限数字，宽度范围为 240–1600。`canvas` 只允许出现在顶层 `callout`，且必须提供唯一、非空的 ID。旧页面可以直接放入白板中浏览与编辑。

Agent 可以使用 `block.insert` 创建独立内容，使用 `block.attrs.set` 修改坐标，使用 `block.text.set` 修改内部文字，使用 `block.remove` 删除内容区域。页面哈希、差异、素材收集和组件依赖收集覆盖所有区块。平移、缩放与吸附属于临时视图状态；内容位置和宽度在拖动结束后保存。

HTML 和网站阅读器使用相同的白板浏览方式。打印会按顺序排出正文与独立内容，Markdown 使用文档内容顺序。模板的空间布局可预览、编辑并应用到新页面。

## 动效与边界

阻力位移连续变化，小幅输入就会产生可见移动。吸附处的累计拉动超过 240 屏幕像素可以离开锚点；松手时，附近可读区域会重新形成锚点。手势停止 220 毫秒后开始回弹或轻微对齐，连续输入期间保持跟手。

回弹使用逐帧积分的阻尼弹簧。新的手势从当下显示的位置接续，可以打断回弹与定位动画。系统启用减少动态效果时，保留阻力位移并直接完成回位。内容编辑器持续挂载，视口移动通过逐帧更新变换完成。

指针捕获支持取消、失焦和中断清理。拖动内容块时暂停视口手势与待执行的吸附，防止内容和视口同时移动。保存、编辑冲突保护、导出和重新载入沿用页面的文件流程。

```sh
npx vitest run src/surface/model.test.ts src/surface/physics.test.ts
npm run build
node src/desktop/surface-ui-smoke.mjs
```
