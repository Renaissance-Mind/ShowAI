# 文档与自由画布

页面默认沿纵向阅读和编辑。持续横向滑动会先产生弹性位移，再展开自由画布。页面下方的「展开画布」提供鼠标和键盘都可使用的入口。

画布可以双向平移，以指针为中心缩放，并在正文旁边放置可编辑内容。正文与外围内容共用页面的自动保存、外部编辑冲突保护、组件环境和导出流程。页面切换视图时保留同一个正文编辑器。

## 操作

| 操作                            | 效果                                               |
| ------------------------------- | -------------------------------------------------- |
| 正文中上下滚动                  | 原生纵向滚动，保留选字、输入和编辑快捷键           |
| 持续横向滑动或 Shift + 滚轮     | 经过阻力区间后进入画布；松开未达到阈值的手势会回弹 |
| 拖动画布空白处、鼠标中键拖动    | 平移视口                                           |
| 在工作区聚焦时按住空格并拖动    | 平移；文本输入中的空格仍用于输入                   |
| 触控板捏合、Ctrl/Command + 滚轮 | 围绕指针缩放，范围 25%–200%                        |
| 画布中的双指触摸手势            | 平移和缩放                                         |
| 「回到正文」或工作区中的 Escape | 回到正文附近，保留纵向阅读位置                     |
| 「总览画布内容」                | 缩小并定位正文与外围内容，最低缩放 25%             |
| 「添加内容」                    | 创建支持文字、图片、图表与其他既有区块的外围卡片   |
| 正文区块菜单 →「移至画布」      | 将原有区块移到正文旁边，保留区块 ID                |
| 卡片标题栏、右下角              | 拖动移动或调整宽度；方向键微调，Shift 加速         |
| 卡片「收回正文」                | 将卡片内部的内容移到正文末尾                       |
| 卡片删除后「撤销删除」          | 在当前页面会话中恢复最近删除的卡片                 |

没有外围内容时，在正常阅读缩放下平移回正文附近，手势结束后会恢复纵向文档模式。存在外围内容时保留画布模式，工具栏持续提供正文和外围内容的定位入口。

表格、代码滚动区域、滑块、下拉菜单和嵌入组件优先接收自身手势。自定义组件可用 `data-surface-gesture="own"` 声明自己处理手势。iframe 内部事件由其自身内容接收。

## 内容模型

外围内容使用现有 `callout` 容器，位于 `document.content.content` 顶层。空间信息存放在 `attrs.canvas`；容器内仍使用现有区块结构。以下是页面内容的一部分：

```json
{
  "type": "callout",
  "attrs": {
    "id": "canvas-note-1",
    "icon": "",
    "tone": "neutral",
    "canvas": { "x": 1064, "y": 120, "width": 360 }
  },
  "content": [
    {
      "type": "paragraph",
      "attrs": { "id": "note-text-1" },
      "content": [{ "type": "text", "text": "相关材料与补充说明" }]
    }
  ]
}
```

坐标使用相对于正文左上角的 CSS 像素，与当前缩放无关。`x`、`y` 必须是 ±1,000,000 范围内的有限数字；宽度范围为 240–1600。`canvas` 只允许出现在顶层 `callout`，且必须提供非空 ID。正文不包含 `canvas` 属性时，格式与旧页面兼容。

Agent 可以使用 `block.insert` 创建卡片，使用 `block.attrs.set` 修改其 `canvas` 坐标，使用 `block.text.set` 修改内部文字，使用 `block.remove` 删除整个卡片。现有页面哈希、差异、素材收集和组件依赖收集继续覆盖这些区块。平移和缩放属于临时视图状态，不触发内容保存；卡片的位置和宽度在拖动结束后保存。

HTML 和网站阅读器保留空间布局与交互组件。普通文档导出仍采用原生页面滚动。打印将正文及外围内容按顺序排版，避免裁掉画布外的内容；Markdown 采用文档内容顺序。模板的空间布局可预览、编辑并应用到新页面。

## 交互边界与验证

横向解锁需要同一手势累计 280 像素、至少 4 个输入事件和至少 80 毫秒；单个事件最多计入 80 像素。220 毫秒无输入会结束本次手势，纵向起始的手势保持纵向，方向反转会抵消横向累计。自动恢复文档使用更小的返回范围，避免在边界反复切换。

视口通过逐帧更新变换移动，正文不会随每个滚轮事件重新构建。拖动采用指针捕获，支持取消和失焦清理；移动中发生外部位置更新时，不覆盖新位置。减少动态效果的系统偏好会关闭回弹过渡。

```sh
npx vitest run src/surface/model.test.ts
npm run build
node src/desktop/surface-ui-smoke.mjs
```
