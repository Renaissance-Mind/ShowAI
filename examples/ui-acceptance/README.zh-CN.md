# 独立界面验收模板

[English](README.md)

把这个目录复制到项目里。以后只需说「按独立界面验收模板交付」，由 Agent 根据当前任务补全括号里的内容。每个任务交付自己的预览，合并前就能验收。

```text
让本任务工作目录里的〈界面改动〉可以直接体验。
从〈页面和示例状态〉开始，验证〈操作 → 可见结果〉，再验证与改动有关的退出、恢复或异常路径。
复用本项目的真实页面和测试工具。若在比较设计，标明这是 mock，以及模拟了什么。
使用本任务的数据，需要服务时选空闲端口。检查在后台运行，原生焦点或系统对话框在隔离环境验证。
在本会话交付所测版本、一个预览入口或文件、怎么试和实际结果。单独指出需要我判断的地方。失败时附预期、实际和对应证据。
```

做 Web mock 时，用浏览器打开[单文件预览样例](preview.html)。样例自带模拟页面和三项检查，覆盖筛选、空结果和清空。把交互和对应断言一起换成本次改动即可。原生端可以直接使用自己的页面和 UI 测试。验收人在另一台设备时，交付对方能打开的构建或可携带文件，并附上同一版本的检查结果。
