# 容量与大文件

先读取当前连接 `showai_capabilities` 返回的 `capacities`；数值单位为 bytes。连接到旧运行时可能仍返回旧规则，插件更新与运行时更新分别核验。

| 对象           | 当前默认预算                              | 计算口径                                                                                    |
| -------------- | ----------------------------------------- | ------------------------------------------------------------------------------------------- |
| 页面结构       | 16 MiB                                    | UTF-8 JSON；完整字符串形式的规范 base64 data URI 按资源引用计算                             |
| 单个资源       | 64 MiB                                    | base64 解码后的原始字节，与同步对象预算一致                                                 |
| 页面资源合计   | 128 MiB                                   | 按不同的完整 data URI 去重；同一 URL 多次使用只计一次                                       |
| 自定义组件实例 | 8 MiB                                     | 实例 props 的结构；其中资源仍分别校验                                                       |
| 组件源码包     | 16 MiB、200 个文件                        | 支持的文本文件合计；200 个文件含资源文件                                                    |
| 组件包资源     | 单文件 64 MiB、合计 128 MiB               | 原始文件字节，独立于源码                                                                    |
| 编译组件       | HTML 16 MiB、inline 代码及样式合计 16 MiB | 编译后的 UTF-8 字节，包含打包进代码的资源和依赖                                             |
| 完整文件       | JSON 与最终 HTML 各 256 MiB               | 包括 base64 膨胀、嵌入组件和阅读器；网站导出逐页面计算                                      |
| 创作请求       | 256 MiB                                   | CLI、浏览器后端与 HTTP MCP 的完整 JSON 请求，包括参数包装                                   |
| 组件发布包     | 每包 256 MiB、一次传输合计 512 MiB        | 可包含源码与依赖闭包，仍检查包的各项预算                                                    |
| 聊天预览       | 1,000,000 bytes                           | 最终展示片段；CDN 片段只计页面数据、图片与自定义组件，打包片段按压缩后计；十进制 bytes      |
| MCP 图像展示   | PNG 8 MiB                                 | image 阅读结果的原始 PNG 字节；与页面图片资源预算分开，超限时缩小 viewport 或 blockIds 范围 |
| 同步清单       | 16 MiB                                    | 当前路径与摘要的元数据；不是项目内容合计大小                                                |
| 同步对象       | 64 MiB                                    | 单个内容对象，资源分开传输；项目仍受服务器账户配额约束                                      |

MiB 为 1,048,576 bytes。除与宿主和同步对象对齐的边界外，这些数值是各阶段的独立默认保护预算，并非经过性能测试的产品最大容量承诺。页面节点数、嵌套深度、文件类型和组件完整性约束继续适用。

容量错误包含对象类型、实际字节与预算；CLI/MCP 返回 `CAPACITY_EXCEEDED` 及 `kind/actualBytes/limitBytes`。规范 data URI 必须是完整字符串且使用无空白的规范 base64。代码、HTML 或 Markdown 字符串中的内嵌 URL 尚未被存储提取为独立资源，会计入该字符串的结构或编译预算。

大视频有三种放法，按读者在哪里看来选：需要随页面分发时，用内置 Video 组件嵌入（受上表单个资源和页面资源预算，对话预览会超限，用 blockIds 选其他区域）；可以联网时，内置 Video 组件填在线地址；只需在本机查看时（如视频原片），自定义组件用 `file:` 链接指向原文件，读者点击后由 ShowAI 工作台播放器打开，不占页面或组件预算，但导出的 HTML 和对话预览中不能播放。`file:` 链接只在自定义组件中有效，写法见 create-component 技能的组件设计「本机文件」。

正式页面先保存，需要展示时再调用 `page_present`。其完整 HTML 和 source 按文件预算生成，`blockIds` 仅控制 inline。聊天超限不会降低页面保存或完整文件预算；根据真实节点 ID 选择独立可读的区域。单个选中节点仍超限时交付完整文件；当前 blockIds 仅选择节点，不提供替换素材的专用预览参数。文件自身超限时减少嵌入依赖；明确导出文件时可用 `page_export` 的 `reader:"cdn"` 写出从 CDN 加载阅读器的在线页（打开需联网），或 `components:"remote"`（需要已验证的组件地址）；本机连接也可按用户要求导出网站，远程 page_export 只支持 html/inline；不能用局部源内容覆盖完整 Page。

本机连接中，大参数可以改从文件读取（page_apply 的 operationsFile、dataset_write 的 valueFile/operationsFile、component_save 的 directory），大结果可以写入文件（page_read、page_diff 的 out，catalog_describe view:"source" 的 out），文件按上表的同一预算检查，避免整段数据经过对话和宿主消息。stdio 服务端同样接受 256 MiB 创作请求。客户端与宿主还可能有独立的消息缓冲预算（MCP SDK 默认 10 MiB）；返回的文本与 structuredContent 也会占用消息空间。读取大量资源时优先使用 outline、blockIds、单文件源码与完整交付路径；完整大消息需要客户端相应配置 maxBufferSize 或使用 HTTP MCP。运行时预算不代表宿主已放宽自己的消息预算。
