# 从成熟页面抽象模板

复制页面是保留一个实例；提取模板还要表达下一次应填写什么，以及哪些结构值得重复使用。

识别稳定部分：叙事顺序、信息层次、交互的用途、组件布局与关系。将本次的人名、日期、指标、结论和项目状态换成填写提示；数组型数据使用空状态或明确标记的演示内容。标题与小节名称保留用途，不写入只有当前实例成立的结论。

contentGuide 按内容角色说明输入、证据与组织要求；related 记录组件或子模板的用途；examples 用自然语言请求与操作顺序说明怎么使用。复用已有组件时保留精确引用，定制组件源码仍留在可编辑包中。组合已有模板时使用 composition 并让 CLI 固定依赖指纹。

当前模板模型保存文档结构与填写说明，由 Agent 根据用户材料生成新页面。不要将文本提示描述为已实现的参数绑定或自动填充系统。直接 `template save --page` 适合保存快照；完整抽象使用处理过的 `--input` 定义。

验证时用另一组材料创建新页面：实例名称和数值不应泄漏；可选区块能删减；图表与组件数据符合 schema；导出仍可打开。保留源页面，模板和验证页面分别保存。
