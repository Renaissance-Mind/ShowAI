# Board 对象编辑

理解已有 Board 的画面时先按 [Board 与 Page 阅读](page-reading.md) 使用 board_read 的图像包、裁切索引与同一快照的原始数据。修改前仍读取完整当前源及 hash/revision。对已有 Board 的局部修改（改图形文字、补画一张草图、整理排布）属于简单任务：合并记录，按本文直接修改并核对结果。绘画节点用 `block.insert` 或 `diagram.insert` 写入，目录组件仍用 `component.insert`。

绘画使用 `drawing` 节点，`attrs.tool` 可为 `pen`、`highlighter`、`rectangle`、`ellipse` 或 `arrow`。`color` 是六位十六进制颜色；`strokeWidth` 为 0.5–40 的本地图形单位。矩形与椭圆可设置 `fillColor`，取六位十六进制颜色或 `none`；缺省为透明。荧光笔使用自由笔画，固定以 35% 不透明度显示，通常配合较宽笔画（如 16）。`points` 为本地坐标，`extent` 为绘画坐标范围；位置与尺寸仍写入 `layout`。分组区域使用原生 `region` 和 `layout.mode: free`，不使用绘画节点；编辑器已不提供新建区域的工具，已有区域可用 ⇧⌘G 取消分组。

矩形、椭圆和箭头可带 `attrs.label`：最多 2000 字的纯文字，可换行，在图形内居中换行显示，箭头文字显示在线段中点，颜色与图形描边一致。`attrs.labelSize` 是文字大小（Board 单位，8–160，缺省 16；编辑器提供 14、16、22、30 四档）。属于某个图形的文字写进它的 `label`，不要另建 Page 叠在图形上。修改已有图形的文字或字号用 `block.attrs.set`，例如 `{type:"block.attrs.set",blockId:"api",attrs:{label:"订单服务",labelSize:22}}`；属性值为 `null` 时删除该属性，可用来去掉文字。显式设置的外框不会因文字变多自动加高，写入后用 board_read 检查文字是否放得下，必要时用 `surface.layout.set` 加高。用 `block.insert` 新增绘画时可以省略能推导的字段：颜色缺省 `#252629`，粗细缺省 2（画笔 2.5、荧光笔 16）；矩形和椭圆的 `points`、`extent` 由同一批操作里 `surface.layout.set` 设置的外框推出，没有外框时按文字自动定尺寸。自由笔画和未绑定的箭头仍需 `points`。

画由方框和箭头组成、读者还要亲手调整的图时，用一次 `diagram.insert` 写入节点和连线：节点给出 `id` 与 `label`，连线给出 `from`、`to` 与可选 `label`；不给坐标时沿连线方向自动排布（`direction` 缺省 `right`），尺寸按文字确定，箭头两端自动绑定到节点。完整字段见运行时 `guide({topic:"whiteboard"})`。节点 `id` 就是写入后的稳定节点 ID，后续可直接用它修改。写入后用 board_read 看图，修正重叠或放不下的文字。节点 `id` 不能与页面已有 ID 重复，连线可以成环。用户要求整理已经连好的图形时，用 `{type:"diagram.arrange",nodeIds:[...],direction:"right"|"down"}` 沿连线重新排布这些对象，它与编辑器“沿连线整理”使用同一套布局：只排列列出的、未锁定、有外框且在同一容器里的对象，整体保持原左上角；列出对象之间的绑定箭头改接到相对的边；连到未列出对象的箭头保持绑定并随之移动；未列出的对象和未绑定的箭头原地不动。列出对象之间至少要有一条箭头，没有连线的列出对象也参与排布。nodeIds 只放图形、Page 等对象，箭头不用列出，会自动跟随；要保留不动的对象（如便签）就不要放进 nodeIds。排布后的整体可能压住未列出的对象，写入后用 board_read 检查，必要时用 `surface.layout.set` 移开；未绑定的箭头不会跟随，需要先绑定或按用户意图处理。结构明确、读者需要逐步查看的流程、时序或分层，通常更适合用 flowchart、sequence-diagram、layer-diagram 等组件。

Board 的工具集中在一条可停靠的工具栏，可拖到画布上、下、左、右边缘，位置保存在本机；选中对象后，复制、层级、对齐与分布、锁定、设置、删除，以及图形或画笔的颜色、填充、粗细和图形文字大小出现在工具栏中，选中组件的既有操作也在这里。选中两个以上由箭头相连的对象时，对齐与分布菜单还提供“沿连线从左到右整理”和“沿连线从上到下整理”。单击对象选中，按住任意位置拖动即移动；再次单击已选文字进入编辑，Escape 退出编辑并保持选中。双击矩形、椭圆或箭头，或选中后按 Enter，编辑它的文字；Escape、⌘Enter 或点击别处完成，文字放不下时图形自动加高。画布空白处双击写文字会建立一个显示名称标题行的 Page；Page 设为 `attrs.frameless:true` 后去掉边框、背景和标题行，用 `block.attrs.set` 设 `frameless:null` 可恢复。右键可添加 Page、文字、组件或粘贴；对象上右键打开对象菜单。多选只显示一组整体手柄。使用矩形或椭圆工具时，悬停已有对象边缘约 180 毫秒可临时抓取对象；画笔、荧光笔和箭头不抓取，连续落笔不会拖动上一笔。视图菜单在点击画布时收起。

`layout[nodeId].locked: true` 表示对象在编辑器中锁定：不能拖动、缩放、被框选或编辑图形文字，仍可单击选中和解锁；它只限制编辑器里的直接操作，`diagram.arrange` 会跳过锁定对象，其他写入照常执行，按用户意图决定是否修改。不需要锁定时省略该字段；只有用户要求解锁时才移除。已有区域的空白内部不遮挡下方对象。

当前编辑器支持撤销和重做。核验时完成一次移动或样式修改，撤销后检查对象属性与位置是否恢复，再重做复核；几何操作和组件内部编辑仍需分别检查。

Page、Board、富组件、文字和绘画共享原生内容树。先读取完整页面的当前 hash、revision 和节点 ID，再查询运行时 `guide({topic:"containers"})`。选择已经存在的对象与父容器，使用现有 `page_apply` / `page_save` 受控写入。保持组件原始数据、精确版本和 Page 正文身份。

对象外框保存在 `document.layout[nodeId]`，坐标相对于直接父容器。移动整个 Page/Board 只改变它的外框，子节点局部坐标保留。`surface.layout.set` 修改外框；`block.move` 改变父容器，若需要新的局部位置，在同一批操作中显式设置外框。不能把容器移入自身或后代。

当前支持的 `rotation` 为 −360 到 360 度，绕对象中心旋转；图像与非箭头绘画可旋转。Page、Board 和交互组件保持正向；非零旋转要求对象位于 Board 或自由布局 region。`contentSize: {width,height}` 是编辑器维护的实测尺寸提示，只在对应宽度下有效，不控制正文或组件高度。保留已有提示，避免编造测量值；内容或宽度变化后以真实阅读器显示核对。

箭头仍使用 `drawing` 节点、`tool: arrow`、本地 `points` 和 `extent`，可附加 `attrs.bindings`。`start`、`end` 各自可为 `{targetId,anchor:{x,y}}`；锚点是目标未旋转外框中的 0–1 比例，省略时取朝向另一端的边中点。两端都绑定的箭头可以省略 `points`、`extent` 和外框，由 Core 计算。目标必须与箭头同级并具有外框，父容器为 Board 或自由布局 region，且目标不能是另一箭头。顺序或网格排版不能提供端点绑定坐标。`block.attrs.set` 只合并所列属性、不能包含 `id`；修改绑定时写出完整的 `bindings` 对象。

目标外框变化会更新连接。单独用 `surface.layout.set` 移动箭头会解除其绑定；同一批操作中变换箭头和目标会保留二者间的关系。相同外框数值的更新不解除绑定。完整文档写入以提供的绑定为准，明确清除绑定才能得到自由端点。

自由区域改为顺序或网格布局时，会解除其直接箭头子节点的绑定并清除直接子对象的旋转；嵌套 Board 或自由 region 保持自己的内部几何。箭头节点继续作为绘画项参与新布局，显示位置由新排列决定；撤销恢复原局部布局、绑定和旋转。删除目标、跨父容器移动目标或局部导出时，不再有效的绑定变成自由端点，并保留最后的位置。复制子树要一起重建节点 ID、layout、surfaceViews 和内部绑定目标，保留原生 surface 结构；优先使用已有模板实例化流程。只复制箭头时，不把它继续绑定到未复制的原对象。

写入成功后重新读取真实结果。核对对象身份、父容器、外框、连接与组件数据；再用实际图像或 HTML 阅读器验证几何和内部交互。hash/revision 冲突说明本次写入失败，应按 [use-showai](../../use-showai/SKILL.md) 的冲突流程比较并处理，不能刷新版本后原样覆盖。共享项目同步不等同于实时多人拖动或光标协作。
