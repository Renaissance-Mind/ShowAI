# Board 对象编辑

理解已有 Board 的画面时先按 [Board 与 Page 阅读](page-reading.md) 使用 board_read 的图像包、裁切索引与同一快照的原始数据。修改前仍读取完整当前源及 hash/revision。

绘画使用 `drawing` 节点，`attrs.tool` 可为 `pen`、`highlighter`、`rectangle`、`ellipse` 或 `arrow`。`color` 是六位十六进制颜色；`strokeWidth` 为 0.5–40 的本地图形单位。矩形与椭圆可设置 `fillColor`，取六位十六进制颜色或 `none`；缺省为透明。荧光笔使用自由笔画，固定以 35% 不透明度显示，通常配合较宽笔画（如 16）。`points` 为本地坐标，`extent` 为绘画坐标范围；位置与尺寸仍写入 `layout`。绘制区域使用原生 `region` 和 `layout.mode: free`，不使用绘画节点。

Board 的工具集中在一条可停靠的工具栏，可拖到画布上、下、左、右边缘，位置保存在本机；选中对象后，复制、层级、对齐与分布、放入区域、锁定、设置、删除，以及图形或画笔的颜色、填充和粗细出现在工具栏中，选中组件的既有操作也在这里。单击对象选中，按住任意位置拖动即移动；再次单击已选文字进入编辑，Escape 退出编辑并保持选中。画布空白处双击写文字，右键可添加 Page、文字、组件或粘贴；对象上右键打开对象菜单。多选只显示一组整体手柄。使用矩形、椭圆或区域工具时，悬停已有对象边缘约 180 毫秒可临时抓取对象；画笔、荧光笔和箭头不抓取，连续落笔不会拖动上一笔。区域与视图菜单在点击画布时收起。

`layout[nodeId].locked: true` 表示对象在编辑器中锁定：不能拖动、缩放或被框选，仍可单击选中和解锁。不需要锁定时省略该字段；只有用户要求解锁时才移除。在区域中框住对象会把完全落在区域内的同级对象移入该区域，位置不变；区域空白内部不遮挡下方对象。

当前编辑器支持撤销和重做。核验时完成一次移动或样式修改，撤销后检查对象属性与位置是否恢复，再重做复核；几何操作和组件内部编辑仍需分别检查。

Page、Board、富组件、文字和绘画共享原生内容树。先读取完整页面的当前 hash、revision 和节点 ID，再查询运行时 `guide({topic:"containers"})`。选择已经存在的对象与父容器，使用现有 `page_apply` / `page_save` 受控写入。保持组件原始数据、精确版本和 Page 正文身份。

对象外框保存在 `document.layout[nodeId]`，坐标相对于直接父容器。移动整个 Page/Board 只改变它的外框，子节点局部坐标保留。`surface.layout.set` 修改外框；`block.move` 改变父容器，若需要新的局部位置，在同一批操作中显式设置外框。不能把容器移入自身或后代。

当前支持的 `rotation` 为 −360 到 360 度，绕对象中心旋转；图像与非箭头绘画可旋转。Page、Board 和交互组件保持正向；非零旋转要求对象位于 Board 或自由布局 region。`contentSize: {width,height}` 是编辑器维护的实测尺寸提示，只在对应宽度下有效，不控制正文或组件高度。保留已有提示，避免编造测量值；内容或宽度变化后以真实阅读器显示核对。

箭头仍使用 `drawing` 节点、`tool: arrow`、本地 `points` 和 `extent`，可附加 `attrs.bindings`。`start`、`end` 各自可为 `{targetId,anchor:{x,y}}`；锚点是目标未旋转外框中的 0–1 比例。目标必须与箭头同级并具有外框，父容器为 Board 或自由布局 region，且目标不能是另一箭头。顺序或网格排版不能提供端点绑定坐标。使用 `block.attrs.set` 修改绑定前先保留该节点的其他必要绘画属性，按当前 authoring 指南核对合并语义。

目标外框变化会更新连接。单独用 `surface.layout.set` 移动箭头会解除其绑定；同一批操作中变换箭头和目标会保留二者间的关系。相同外框数值的更新不解除绑定。完整文档写入以提供的绑定为准，明确清除绑定才能得到自由端点。

自由区域改为顺序或网格布局时，会解除其直接箭头子节点的绑定并清除直接子对象的旋转；嵌套 Board 或自由 region 保持自己的内部几何。箭头节点继续作为绘画项参与新布局，显示位置由新排列决定；撤销恢复原局部布局、绑定和旋转。删除目标、跨父容器移动目标或局部导出时，不再有效的绑定变成自由端点，并保留最后的位置。复制子树要一起重建节点 ID、layout、surfaceViews 和内部绑定目标，保留原生 surface 结构；优先使用已有模板实例化流程。只复制箭头时，不把它继续绑定到未复制的原对象。

写入成功后重新读取真实结果。核对对象身份、父容器、外框、连接与组件数据；再用实际图像或 HTML 阅读器验证几何和内部交互。hash/revision 冲突说明本次写入失败，应按 [use-showai](../../use-showai/SKILL.md) 的冲突流程比较并处理，不能刷新版本后原样覆盖。共享项目同步不等同于实时多人拖动或光标协作。
