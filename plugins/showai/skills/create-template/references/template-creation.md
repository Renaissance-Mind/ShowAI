# 直接创建模板文件夹

从重复的读者任务、每次材料、固定结构和可选内容确定模板。结构未明确时给少量有实质区别的方向；已明确时直接制作。用户选择充分明确后持续完成包和真实应用验证。

按 [create-template](../SKILL.md) 创建 README.md、guides/、可选 components/ 和 page.json。README 的 JSON frontmatter 是可解析的元信息；正文保持简短，详细方法放在所属阶段。六阶段必须声明，确实没有额外要求的阶段设为 null，继承系统指南。Markdown 阶段文件夹以 README.md 为主入口，细节子文件按需读取。

意图和证据阶段明确读者、输入、来源和缺项；理解阶段确定层次与先备关系；设计阶段说明对象、关系、布局、状态和静态/窄屏表达；制作阶段说明具体材料怎样形成组件与页面；评审阶段给出与读者任务对应的检查。阶段说明不复制整份系统基线，也不为填满目录增加无意义内容。

组件库使用现有的 source/schema/documentation 合同，本地名字由 README 声明，注册器生成隔离的实际 ID 并固定版本。没有自定义组件就留空。页骨架可选；它保持容器、阅读顺序与可复用组件，实例事实替换为真实的填写提示或空状态。系统规则不因页骨架省略而关闭。

用 template_save 的 portable bundle 保存，新阶段/包内容发布新模板版本，组件代码变化单独升级组件版本。调用 template_context 获取真实引用与组件索引，按当前阶段 template_guide，再用 template_apply 制作实例。检查真实内容、主要交互、静态方式与完整交付。只有验证页填写完成，才说明已验证对应材料的使用。

指导信息和页实例分别维护：改变复用方法更新包，改变本次数据更新实例。用户提出的反馈融入新内容，避免在模板正文逐条回应修改历史。保留原实例，使用不同材料验证复用。
