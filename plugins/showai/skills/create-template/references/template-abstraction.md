# 从成熟实例提炼模板

先读取完整原 Page、hash/revision 与精确组件引用。识别在不同材料中仍成立的读者任务、理解关系、阅读顺序、视觉编码、交互与检查；本次发现、日期、数值和素材来源属于实例。不要仅复制截图或章节名称。

按 [create-template](../SKILL.md) 的文件夹格式提炼。README 记录名称、用途、版本、场景和阶段/组件入口，短正文解释整体用法。guides/ 分别保存各阶段需要的判断与填写方法；系统已经规定的共性直接继承。将实例中的组织经验提炼为理解路径与视觉设计阶段的判断方法，结合新材料重新确定页面逻辑和结构。

抽取组件前检查是否需要复用代码。仅改输入/布局够用时沿用公共能力；确实有专题图形或交互需要才放入 components/。该库使用本地 ID、真实 schema、默认空状态和版本化使用/开发说明；注册器生成实际引用，不能写死另一个项目的路径或指纹。

保留原实例。新包保存后，以另一份材料应用，检查密度、概念展开、交互和静态方式。验证发现某区域只适合原实例时，缩小适用场景、调整可选条件或改成实例内容。材料不足时交付可用结构和未验证范围，避免编造实测结论。

后续修改发布新模板版本；组件代码改变也升级组件版本。旧 document/composition/contentGuide 定义仍可读取或显式维护，新建抽象采用 README 与阶段指南。需要组合时使用基础组合能力，不要求每个阶段执行嵌套处理。
