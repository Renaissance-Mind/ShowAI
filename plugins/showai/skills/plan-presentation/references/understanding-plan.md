# 理解规划

先识别概念、步骤、证据和条件之间的关系，再选择读者的主阅读路径，最后决定屏幕上如何显示。概念网络允许多父关系；阅读路径可以是一棵深度不同的树；一个理解节点可以跨多个画面。章节深度不自动决定折叠层级。

## 材料底稿

重要主张记录来源及具体位置、事件或测量日期、条件、能支持的范围和不确定性。区分事实、作者主张、分析推断、设计建议和生成示意。材料冲突时说明口径与条件差异，不以平均或多数投票消除冲突。

论文按任务、方法、设置、证据和局限核实；数据分析核对粒度、单位、样本和计算；教程核对实际入口、版本、操作与反馈。通用任务没有专门采集流程时，保留这项轻量的来源与支持范围检查即可。

停止收集的条件是材料足以回答主要问题、支撑关键判断并说明重要限制。尚缺决定性材料时继续查询或缩小结论。时间范围延伸到未来时，以真实检索截止日为界，单独说明已公开的后续计划。

## 规划节点

| 字段     | 判断标准                               |
| -------- | -------------------------------------- |
| 读者任务 | 这一部分读完能解释或完成哪件事         |
| 核心回答 | 一句明确的结论或关系                   |
| 先备条件 | 需要哪些概念；缺少时在哪里补充         |
| 展开内容 | 必要定义、过程、例子、反例、证据与边界 |
| 表达候选 | 哪种图形或文字能直接表达该关系         |
| 显示位置 | 主线可见、就近解释、补充展开或来源附录 |
| 通过条件 | 用什么复述、判断或操作检查理解         |

从读者当下认知开始。第一级列出各环节的理解任务；第二级展开完成任务必须讲清的内容；遇到尚不理解的概念或关系时继续细化。每个分支可在不同深度停止。

停止展开：读者能够完成对应任务；关键术语已有可理解的定义或例子；适用条件清楚；继续深入不会显著改善当前目标。共享概念只定义一次，在使用处短释和定位。专家可直接进入差异和证据，新手按需要增加例子与逐步变化。

会改变结论或操作正确性的条件必须直接可见。展开操作用于补充证据、推导或更多例子，不能成为读懂主线的必要猜测。对疑似误解，用可核实的定义、案例或反例解释有影响的前提，再回答原任务。

## 填写示例

主题：如何为比较材料选择模板。

- 一级：确定阅读任务；检查结构是否合适；验证真实内容。
- “结构是否合适”展开为必需材料、阅读顺序、内容密度。
- “必需材料”继续展开为共同标准、可比口径、缺项及其对结论的影响。
- “阅读顺序”用标准→差异→取舍和一个具体例子即可停止。
- “内容密度”按桌面与窄视口两种布局解释，不要求同样的层数。

该节点的通过条件：读者面对一份材料不齐的比较任务，能说明可采用的结构，并指出暂时不能给出的结论。
