# ShowAI plugin

ShowAI delivers a single interactive page: a title, content, and useful controls inside the content. Its React reader is bundled into one HTML file. The page opens offline without a workspace, account, API key, MCP server, or background process. A small corner menu contains source download, appearance, and print options.

The plugin provides the `show-document` skill, a bundled reader, and a dependency-free renderer requiring Node.js 20 or later. From this repository, run `npm run build` to prepare the generated `assets/`, `scripts/`, and skill references before distributing the plugin folder.

```sh
node plugins/showai/scripts/render-artifact.mjs examples/welcome.showai.json ./output/growth.html
```

The source contains one document. The output contains that page's content, styles, runtime, and source data; it preserves chart exploration, table filtering, image viewing, and calculator inputs. Reader interactions are temporary. To revise content, edit the JSON or open it in the ShowAI canvas and export again.

Every image must be an embedded raster data URI. The browser canvas can embed remote images during HTML export if their server permits the request. Supporting links require a network connection when opened.

The repository's `.agents/plugins/marketplace.json` exposes **ShowAI Local** to compatible Codex desktop clients. Build first, then install ShowAI through the desktop plugin directory. Packaging does not install or activate the plugin. A zipped plugin folder is a distributable package; the HTML generated by the skill is the single-page result shown to the user.

Package format: [OpenAI plugin documentation](https://developers.openai.com/plugins/build/plugins).

In a conversation host supporting inline visualization, add `--inline` to generate a fragment under 1 MB and return it using the host's inline content reference. This package remains skill-based; native MCP Apps tool/resource integration is a separate transport.
